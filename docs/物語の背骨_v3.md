## 0. v3 の方針

作者の指摘：
- 理屈っぽいけど、内容が理解しにくい。「なぜ？」が抽象的。
- 各時代が有機的につながるように。時代を増やしすぎず、同じ時代の別のフィールドを。古代はテンポを変えるのにいい（ものによっては採用）。
- **共感と感動を生むストーリーに。伏線は上手に回収する**。
- **行動の必然性と、目的が明確であること**。行き当たりばったりのお使いにせず、ストーリーを進めながらやることが明確になっていく。

Claude と Codex で決めたこと（理由は §11.1）：
1. 画面で使う言葉は「黒い輪・欠け・錨・守りの壁」の 4 つだけ。説明は三文にして、明かす時期を章ごとに分ける。
2. 各章を「誰の、何を助ける話か」の一文にする。その人が目の前の仕事をやり遂げるのを手伝った結果、ネクマックスの明日も守られる。
3. **守ったことを失敗として裁かない**。成長は「守ること」に「安全に戻すこと」を足すこと。
4. 決着は「黒い輪の口を外す → もう吸われていないと確かめる → 守りを解く → 朝」。朝は勝利の結果。
5. **ソラは忘れる。それでも、前の自分が残した仕事を受け取り、今の自分の判断でネクマックスを支える**。中盤で三度、ソラ自身の判断で状況が変わる場面を置く（11章で冒険を進める・12章の帰還でおはるの書き足しに気づく・15章の帰還で最後の作戦を引き受ける）。最後の「昨日のこと、覚えてるよ」は、遊んだ時間への返事になる。
6. 12章 → 13章は順番を固定し、異変を段階的に強くする（刻印 → 右腕 → 名前 → 鉱石）。
7. 台座の二択はやめる。発見の主役はソピア。
8. 山場では台詞で主題を言い直さない。手を差し出す・図を写す・道具を持ち上げるなど、**動作と間で気持ちを渡す**。

## 1. 物語の芯（共感と感動の柱）

> ソラ（8歳）「昨日のこと、思い出せなくても大丈夫。今日から、いっしょに思い出をつくろう！」

- 二人はこの言葉から 15年、思い出を作ってきた（導入編の独白「ソラとつくった思い出なら、15年ぶんある」）。
- 祭りの夜から、同じ一日がくり返す。**ソラは毎朝、前の日を忘れる。覚えているのはネクマックスだけ**。いっしょに作ったはずの思い出が、ネクマックスの中にしか残らない。プレイヤーが最初に共感する寂しさ。
- それでもソラは、羅針盤に自分の字でメモを残す。「ネクマックスを信じて」。そして次の朝のソラは、覚えていないのに、そのメモと前の自分の調べた物を受け取って、**今の自分の判断で**続きを始める。**忘れても続く信頼**が、二人の関係の芯。
- 物語の終わりは、「止まってしまった思い出の続きを、また作れる」朝。ソラが取り戻すのは、全部の周の記憶ではなく、**直前の一日をいっしょに覚えている、ふつうの暮らし**。覚えていない冒険は、残されたメモを二人で読めばいい。

もう一本の柱：**仲間と小さな仕掛けを動かしてきた経験を、自分が町を守り続けている大きな力にも使えるようになる**。7章の水門（源兵衛とおはる）、10章の塔（ミチ）で「支えて、合図で離す」は成立している。15章でその意味が「守りを、安全に終える」へ広がり、16章で最後の合図をソラに委ねる。

## 2. プレイヤーに伝える説明（三文）と、明かす時期

1. 空の黒い輪は、**明日を食べる生き物**。祭りの夜、明日を楽しみにする人が集まったナンバタウンへ来た。
2. ネクマックスが知らないうちに町を守っていた（同じ一日のくり返し）ので、黒い輪は今度は、**ネクマックスが生まれるまでの過去に食いついた**。
3. **ネクマックスが生まれるきっかけが消えたら、町を守るネクマックスもいなくなる**。だから、過去の人たちを助けに行く。

| 時期 | プレイヤーに分かること |
|---|---|
| 1〜8章 | 空の黒い輪が町を飲み込み、同じ一日がくり返す。覚えているのは自分だけ。背中の鉱石は量産型に無い。1726年にも同じ黒い輪がいて、人を助けて仕掛けを正しく離すと、その時代の輪が薄くなる |
| 9章 | ソラの仮説：黒い輪は「明日のはじまり」になった出来事（錨）をかじっている。過去の異変が、自分の体にも出ている（固定具の刻印が薄れる） |
| 10章 | 過去の人を助けると、自分の体が戻る。未来の黒い輪の記録も、少しだけ小さくなる |
| 11章 | 町を囲む壁が、自分の背中の鉱石とつながっている（誰が作ったかは、まだ） |
| 14章 | 壁と巻き戻しを動かしていたのは、自分のとっさの反応。同じ朝へ戻るたび、過去の食い込みが深くなる |
| 15章 | 閉じたあと、安全に戻す方法がある |
| 16章 | 口を外して、守りを解いて、明日へ |

画面では、明日が食べられる様子をはっきり見せる：開場予定の看板、来年の約束の貼り紙、未来の街の展示が、黒い輪へ吸い込まれていく。**明日を楽しみにした人に落ち度がある描き方はしない**。

## 3. 画面で使う言葉

| 言葉 | 意味（画面で分かる形） |
|---|---|
| 黒い輪 | 空に浮かぶ、明日を食べる生き物。名前「オルム」は 14章まで誰も口にしない |
| 欠け | 黒い輪に明日を食べられかけて、黒く動き出した物（敵）。倒すと、捕まっていたものが光になって元の持ち主へ戻る |
| 錨 | 黒い輪が、その時代に食い込んでいる場所 |
| 守りの壁 | 祭りの町を囲む、白くかすんだ壁（4章で外へ出られなかった壁） |

- 収集物「時のかけら」（1970年に実装済み）は「欠け」と紛らわしいので、**「時のしずく」に改名**し、見た目も丸い光のしずくにそろえる（§11.3）。
- 欠けを倒して戻るのは「食べ尽くされた時間」ではなく「**奪われかけて、捕まっていたもの**」。最終戦で戻る明日も同じ。

## 4. 目的の階段：ストーリーを進めるほど、やることがはっきりする

各章は「いま何のために、何をするか」が一つに決まっている。章の終わりに分かったことが、次の章の目的を生む。目的が途中で変わるときは、**必ず一言で理由をつなぐ**（下の「つなぎの一言」）。

| 章 | 大きな目的 | いまの目的 | つなぎの一言・章の終わりに分かること |
|---|---|---|---|
| 1〜5 | ソラと祭りの夜を越えたい | 夜を止める方法を試す | 背中の石は量産型に無い → 石の正体を知りたい |
| 6〜8 | 石の正体を知りたい・帰りたい | 2026年・1726年で人を助ける | 1726年にも同じ黒い輪がいた。人を助けて仕掛けを正しく離すと、その時代の輪が薄くなる |
| 9 | 夜を止めたい | 持ち帰った話をソラに伝え、次に行く記録を決める（羅針盤） | 固定具の刻印が、受け取ったときより薄い → 過去の異変が、自分の体に出ている。針が 1970年を指す |
| 10 | 自分の体を戻したい | ミチを助けて錨を外す | 過去の人を助けると体が戻る。黒い輪は記録の上で少し小さくなったが、夜には消えない |
| 11 | 夜を止めたい | **町を囲む境目の正体を確かめる**。ネクマックス「町の外へは出られないんだ」→ ソラ「地上だと境目は白くかすんで近づけない。地下の避難路なら、境目の真下まで行ける。……針が止まっている間に、調べよう」 | 「やっぱり、町はぐるりと囲まれてる。でも、この壁は君の石に反応した。次は、この反応を調べよう」 → 直後に右腕の異変。ソラ「壁の記録は残せた。今は、君の腕を先に止めよう」（壁の調査は 14章で再開する） |
| 12 | 体を戻したい | 源兵衛に腕の金具のことを聞く。着いてすぐ「お前の腕と、あの水車……同じところが止まっとる。水車を頼む」 → **村へ水を通す** | 自分の腕の仕組みは、源兵衛とおはるの工夫から来ている。ソラが絵図の書き足しに気づく |
| 13 | **ソラに名前を呼んでほしい** | 佐伯の実演を成功させる。佐伯「この実演がなくなったら、ロボットを作る仕事そのものが始まらないんです」 | 自分は、たくさんの人の仕事が重なって生まれた。ほどいた錨は、どれも自分が生まれる道の上にあり、すべて同じ夜を指す |
| 14 | 夜に何が起きているか知りたい | 鉱石の記録を見る → 「この夜と、同じ反応が前にもある。2068年……地下駅で、何を守ったんだろう」 → 記憶の部屋 | **自分が町を守っていた。守ったことは間違いではない。でも、戻し方を知らない** → 目的が一つにまとまる：守りを安全に解く方法を見つけ、黒い輪の口を外して、ソラと明日へ行く |
| 15 | 守りを安全に解く方法を知りたい | ソピアを助け、石が見つかる場所を守る → 錨を外したあとに「町を安全に戻す方法は、まだ分からない」 → 昔へ | 閉じたあと、外の安全を確かめて、合図で手を離せば戻せる。ソラ「ここからは、私の仕事」 |
| 16 | ソラと明日へ行く | 口を外し、守りを解く | 初めての明日 |

過去の時代へ行くときは、**体の異変**と**羅針盤の針**の二つで行き先が決まる（10・12・13章。羅針盤は、ネクマックスにつながる記録のうち、黒い輪に噛まれて震えているものを指す。15章は消えていく開発記録と IDO アーカイブで決まる）。11・14章は、前の章で分かったことを確かめに行く。行き先の時代では、**助ける相手と、その人がやり遂げたい仕事**が一つだけある。遊びの障害は、その仕事の邪魔として出てくる（部品を集めて回る形は 10章だけ）。

## 5. 章ごと（9〜16章）

### 9章 2086年「羅針盤」（一部実装済み。8章の帰還からそのまま続く）
- **一文**：ソラが、忘れても続けられる調べ方（羅針盤とメモ）を作る話。
- **きっかけ**：帰ってきたネクマックスが、1726年の水門で黒い輪が薄くなったこと、2026年で佐伯に固定具をもらったことを話す（実装済み）。ソラが固定具を見る。「この刻印、『佐伯』……受け取ったばかりなのに、もうかすれてる」（これから足す。8章で佐伯が固定具に名前を刻む一言も足す）。
- **流れ**：ソラが IDO のアーカイブで、「明日のはじまり」になった出来事の記録だけが欠けているのに気づく → 展示のリングと絵図の写しで羅針盤を作る → 針が 1970年の記録に振れる（行き先の根拠）→ ソラがメモを書く。ネクマックス「羅針盤は、ぼくが持っておく。ぼくが持ってる物は、朝に戻っても消えないんだ。源兵衛さんの金具みたいに」（メモが次の周に残る理由。実装済み）。
- ソラの説明は仮説を一つに絞る（「黒い輪は、明日のはじまりになった出来事をかじってる」）。欠けた記録の一覧と刻印は、プレイヤーが自分の目で見比べる（実装の説明の台詞を短くする。§12）。
- 実装の台詞「博覧会の展示、発明の発表会、旅立ちの港……」の「旅立ちの港」は、港の章が無いので「村の水車、遺跡の発見」に直す（10・12・13・15章の錨を、ここで先に見せておく）。
- 会場の屋台に「長命草だんご――一株で一日長生き」の看板（12章の伏線）。
- **分かること**：過去の異変が、自分の体に出ている。

### 10章 1970年 万博（実装済み）
- **一文**：ミチが、忘れられた先輩の仕事を完成させる話。
- 戻ると、固定具の刻印がはっきり戻っている（これから足す一行）。ソラは羅針盤に残った前の一覧と比べて、消えていた展示が戻ったと気づき、ミチのノートの持ち主が「佐伯」だと知る（実装済み。確かめるのは 13章）。
- 1970年で錨を外した直後の「鉱石が軽くなった」（実装済み）は、錨の負担が軽くなった感覚。帰ってからの「光が少し弱い」は、巻き戻しの消耗。二つは別のこととして扱う。ソラの「前より少し弱い」は、15年見てきた普段の光と比べている（前の周を覚えているわけではない）。
- **分かること**：過去の人を助けると、自分の体が戻る。ただし夜の黒い輪は少し小さくなっただけ。

### 11章 2086年 地下の旧駅「下からの道」
- **一文**：ソラと二人で、町を囲む境目の正体を確かめる話（ソラと一緒に歩ける、唯一の冒険）。
- **きっかけ**：夜の黒い輪は消えない。羅針盤の針は止まったまま（10章の終わりの「針が動くのを待とう」を受ける）。ネクマックスが、町の外へ出られないことを話す（4章）。ソラ「……私と、ゲートを出ようとしたの？ 覚えてないけど……」。
  - 4章でその試みを選ばなかったプレイヤーもいるので、ここで南のゲートを一度だけ短く試す（白くかすみ、広場へ戻される。選んでいた人には「やっぱり」の一言だけ）。
  - ソラ「地上だと、境目は白くかすんで近づけない。でも地下の避難路は、町の外までつながってるはず。下からなら、境目の真下まで行ける。……針が止まっている間に、調べよう。私、あの駅は知ってるの」。
  - 「町のみんなを外へ逃がす」は目的にしない（4章の②で、逃げた先から先に消えていくのを見ているため）。
- **ソラが冒険を進める**：通路の判断、古い装置の操作、安全の確認はソラの担当。ネクマックスが渡る前に、ソラが離れた場所から安全を確かめて合図する（16章の連携の準備）。
- **流れ**：
  1. 白い壁：触ると、背中の鉱石と同じ響きがする。
  2. 閉鎖された地下街：シャッターの重りをクローで引いて通路を開く。広い踊り場で一度だけ欠けと戦う。
  3. 水没したホーム：天井の配管へ飛びつき、振り子で向こう岸へ。途中に、足をつけられる広い場所を置く。
  4. 回収施設の跡：ソラ「ここでね、君を見つけたの。8歳のとき」。段差でソラが先に降りて、手を差し出す。「ここ、あのときも降りにくかったんだ」。ネクマックスは覚えている。プレイヤーがその手を取って進む（ソラ自身の思い出なので、ソラも覚えている）。
  5. 最深部：出口は無い。壁は町の下までぐるりと閉じていた。壁の根元が、ネクマックスの鉱石の光と同じ脈で光る。
     > ソラ「やっぱり、町はぐるりと囲まれてる。……でも、この壁、君の石に反応した。次は、この反応を調べよう」
  6. （任意・帰り道）旧駅の広場に、工事で掘り出された**舟をつなぐ大きな石**が展示されている。ソラ「ここ、昔は港だったんだって。……少し歩いてみる？」。石に残る IDO 記録で古い港（難波津）を 2〜3分歩き、石に結んだ綱を、港の娘の合図で離す。見なくても本筋は進む（§11.2 Q6）。
- 背中の鉱石が強く光り、**異次元拠点**（ネクマックスの中にある小さな整備室）が開く。装備の付け替えができるようになる。
- 整備室で、源兵衛の古い金具を鉱石に近づけると、一瞬だけ知らない地下の映像と音が戻る（14章の記憶の部屋への導線）。保全記録の中に、今のものとよく似た「2068年」の記録が見つかるが、映像は途切れ途切れで読めない。操作の欄には「閉じる」だけがあり、その下に読めない行が一つある（15章で分かる「戻す」手順の跡）。
- （§11.2 Q1 で作者が A を選んだ場合）ソラが怖い場所を歩くときの小さな癖を一つ置く：ネクマックスの手を三回きゅっと握りながら、「いち、に、さん」と小さく数える。説明の台詞は付けない。
- **分かること**：壁と自分がつながっている事実（誰が作ったかは 14章）。プレイヤーが「ネクマックスが作った？」と推測するのはよい。
- **戦闘とテンポ**：戦闘は少なく、静かな探索。ボスは置かず、壁と鉱石が同じ光で応える発見を頂点にする。帰り道の古い港（任意）で一度明るくなる。

### 12章 1726年 浜の里「長命草と水車」
- **一文**：おはるが、倒れたおじいちゃん（師匠）に代わって村へ水を通す話。
- 人物：おはるは源兵衛の孫で弟子（導入編の「おじいちゃん」を維持）。浜の里は、源兵衛の娘でおはるの母・**おせい**（村の薬師）が暮らす村。おはるは、からくりを学ぶために母の反対を押し切って、町のおじいちゃんのところへ出てきた。
- **きっかけ**：11章の最深部から戻った直後、右腕で**仕掛けを長く支える（保持する）**ことができなくなる（撃つ・引く・飛びつく・振り子はできる）。ソラ「壁の記録は残せた。今は、君の腕を先に止めよう」。整備室でソラが調べても分からない。羅針盤が 1726年に振れる。目的：**金具を知っている唯一の人、源兵衛に聞きに行く**。時期は 7章の水門から数か月後。同じ年でも、源兵衛の次の仕事（娘の村の水車）に別の錨が下りている。
- **流れ**：
  1. 仕掛け横丁の工房は空。おはるの置き手紙「おじいちゃん、浜の里で倒れた。うちの村へ来て」。
  2. 横丁の舟着き場から、舟で川を下る（7章で直した水門のそばを通る）。橋桁に引っかかった流木をクローで引く・乗り込んできた欠けを倒す・岸へ飛び移る、の短い場面。
  3. 浜の里：長命草の畑が黒く枯れ、作りかけの水車は止まり、村の人は水車のことを忘れはじめている（錨）。源兵衛は水車を守ろうとして欠けにやられ、熱で寝込んでいるが、一言話せる。
     > 源兵衛「お前の腕と、あの水車……同じところが止まっとる。わしの熱を下げても、それは直らん。……水車を頼む」
     → ここで二つの仕事が見える：源兵衛の熱を下げる（長命草）、水車を動かす（自分の腕と同じ錨）。
  4. おせい「長命草を煎じたら熱は下がる。けど畑のは全部枯れた。残ってるのは、崖の途中の棚だけや」。歩いては降りられない棚。
  5. **はばたき**：源兵衛の図面の箱に「凧の羽」の図。おはるが初めて自分で組み、ネクマックスの左腕に付ける。低い段差で試してから、水車の作業やぐら（クローと足場で登れる）から崖の棚へ滑空する。
  6. **村を一周する道**：作業やぐら → 薬草の棚 → 浜（網や舟の形の欠け）→ 用水沿い → 家と水車。同じ道を戻らない。
  7. 長命草で源兵衛の熱は下がるが、まだ動けない。源兵衛「長命草はな、一日ぶんの明日をくれる草や。……水車は、おはる、お前がやれ」。おせい「お父ちゃんは昔から、人の言うこと聞かへん」。
  8. 水車に絡んだ重い欠けを、はじくとクローで除く（独立したボスではなく、水車を動かす一続きの場面）。
  9. **錨を外す**：ネクマックスは支えられない。おはるが「荷を受け止めてから留め具を外せる仕掛け」を考え、村人と一緒に支える。田植え歌の区切りで、ネクマックスが錨を外す。
  10. 水車が回り、水が畑へ。プレイヤーは水を追って畑までたどる。長命草が青くなり、村が水車を思い出す。おせい「あんたの選んだ道……ええもん作るやないの」。おはるは、自分の仕掛けをおじいちゃんの絵図に書き足す。
- **帰還（ソラ その二）**：右腕が戻る。今朝のソラは何も覚えていないが、羅針盤のメモと、戻ってきた源兵衛の絵図を比べて、気づく。「この書き足し……前の私のメモには無かった。おはるさんの字？ 荷を受け止めてから外す仕掛け……これなら、ずっと腕で支えなくていい。この部分、写しておこう」。ソラが図を写し、ネクマックスが持ち歩く。これが 13章の実演機になる。
- **分かること**：自分の腕の仕組みは、源兵衛とおはるの工夫から来ている。

### 13章 2026年 電気街と川沿い「絵が仕事になる日」
- **一文**：佐伯が、社長の構想を実物で支える話。
- **きっかけ**：朝の整備で、ソラがネクマックスの名前を呼ぼうとして、出てこない。「ね……ごめん。君の名前……」。それでもソラは、いつもの手順で腕を点検しはじめる（名前は消えても、関係のすべてが消えたわけではない）。羅針盤のメモの「ネクマックス」の文字も欠けはじめているが、「信じて」の字は残っている（周を越えて持ち歩ける物と、過去から消えていく名前は別、と一度見せる）。羅針盤が 2026年の IDO 発表会の記録に振れる。

  1. なんば（6章の場所）に着く。社長のスケッチブックの絵が白くなり、社員はロボットの企画を思い出せない。発表会からロボットの話が外されかけている。社長自身も「なんで僕、ロボットなんか描いてたんやろ」。社長はネクマックスを見ても首をかしげる。「……どこかで、会うたかな」（2086年のソラと同じことが、ここでも起きている）。

### 14章 2086年「守りの正体」
- **一文**：ネクマックスが、自分が何を守ってきたのかを知る話。
- **きっかけ**：ほどいた錨が、どれも「10月18日、夜」を指す。鉱石の光が、はっきり弱くなっている。目的：**夜に何が起きているのか、鉱石の記録を見る**。
- **流れ（今の記録で証明する）**：
  1. 整備室でソラが、鉱石の保全記録を開く。「保全の発動：10月18日 20時41分」。祭りの夜、黒い輪が町を飲み込む直前（2章で背中の鉱石がまぶしく光った瞬間）の映像と、時刻がぴったり重なる。
  2. 記録には、発動のたびに同じ声が残っている。「もう一度、あの朝に」。1970年で錨がほどけたときに聞こえた声。**自分の声だった**。
  3. 発動の回数と、過去の記録の欠け方が、ぴったり対応している（回数が増えるほど、刻印・絵図・名前の欠けが深い）。**同じ朝へ戻るたび、錨の食い込みが深くなっていた**。
  4. ソラが壁の内と外を図にする。「黒い輪の本体は、壁の外。君がクローで触ってたのは、壁に映った姿だったんだ」（4章「すり抜ける」の答え。16章で体で確かめる）。
- **流れ（なぜ閉じたのかを、昔の記憶で理解する）**：
  5. 「この夜と、同じ反応が前にもある。2068年……地下駅で、何を守ったんだろう」。ほどいた錨の記録がそろうと、11章では途切れ途切れだった 2068年の映像がつながり、**記憶の部屋**としてひらく（11章で源兵衛の金具が見せた一瞬の続きが、ここで見える）。中は 2068年の地下（11章と同じ場所の、18年前。浸水と崩落の救助の夜）。
  6. 前半：**二本のワイヤー**で救助の道を作る。片方で崩れかけた扉を支え、もう片方で自分が渡る（11章で振り子の支点だった配管が、ここでは救助のために使った物だと分かる）。
  7. 後半：取り残された 5歳の女の子を左腕で抱え、右のクローと移動で脱出する。11章では軽く渡れた場所を、重さを感じながら慎重に渡る。女の子が身を縮めたら足を止め、落下物からかばう。抱えている間は戦わない。
  8. （§11.2 Q1 で A のとき）暗くて顔は見えない。女の子はネクマックスの手を三回きゅっと握って、「いち、に、さん」と数える。11章のソラと同じ間と仕草。説明はしない。プレイヤーが気づく。
  9. 天井が落ちる瞬間、背中の鉱石が**とっさに閉じる**。女の子は救助隊の前へ押し出され、ネクマックスだけが 1723年の川へ落ちる。溺れかけていた三年前の源兵衛を、クローで岸へ引き上げる（7章「その腕で引き上げてくれたやろ」の回収）。そのとき金具が一つ外れて、源兵衛の手に残る。光に引き戻されて地下へ戻ったとき、機体はぼろぼろで、記憶は鉱石の奥へ閉じこめられた（新仕様 §8.2）。
- **帰還**：説明より先に、ソラが傷んだ腕に触れる。
  > ソラ「あのときも、手を離さなかったんだね」
  > ソラ「君の力が、みんなを助けてくれたんだよ。……今度は、安全に戻す方法を覚えよう。いっしょに」
- **分かること**：守ったことは、間違いではなかった。2068年も 2086年も、とっさに閉じたからみんなが助かった。ただ、**閉じたあと、安全に戻す方法を知らなかった**。ここで目的が一つにまとまる：**守りを安全に解く方法を見つけ、黒い輪の口を外して、ソラと明日へ行く**。
- **二本のワイヤー**：ソラが予備のパーツを整備して、左右に付ける（記憶で使い方を思い出した）。
- **次へ**：鉱石の開発記録「2028年、カンボジアで発見」の行が、一文字ずつ消えはじめる。

### 15章 2028年 カンボジア → クメール王朝の時代 → 2028年「夜明けに手を離す」
- **一文**：ソピアが、祖母から受け取った歴史を残す話。ネクマックスは、守りを安全に終える手の離し方を覚える。
- **きっかけ**：鉱石の「発見」の記録が消えていく。発見が無かったことになれば、ネクマックスの鉱石はこの世に無い。ソラが IDO アーカイブで「IDO カンボジア 第1号（登録：マツイ／2028年）」の記録を見つける。開発資料には「閉じる」操作しか残っていないが、「遺跡の台座には、その続きらしい文様があった」と一行だけ書かれている。目的：**石が見つかる場所を守り、閉じたあとの続きを知る**。
- **2028年に起きていること**：社長は 13章で話したとおり、カンボジアの**教育と観光のプロジェクト**を立ち上げた。観光地の遺跡に IDO の石標を置き、子どもたちが自分の国の歴史を歩いて学べるように、旅の人がクメールの都の本当の姿を見られるようにしている。最後の一か所が、考古学者ソピアが祖母の子守歌を手がかりに密林で見つけた遺跡。ここ数日、みんなが遺跡のことを忘れはじめ、明日の朝で調査は打ち切られる。
- **流れ**：
  1. 遺跡の入口、置いたばかりの IDO の石標の前で社長と再会。「……2年ぶりやな。いや、君にとってはどのくらいぶりや？」。ソピアは作業しながら、いつも同じ歌を口ずさんでいる（祖母の子守歌）。
  2. **ソピアを助けて錨を外す**（2028年側の能力の総まとめ：回廊をクローで渡る・崩れた石をはじくで割る・調査用の鉄の足場をじしゃくで引く・崖の水路をはばたきで越える・二本のワイヤーで崩れる梁を支えながら渡る。番人戦は 2028年側に一度だけ）。外す合図は、ソピアがはっきり歌う子守歌「夜が来たら石の家へ、朝が来たら門をひらけ」。
  3. ソピアの十年の調査記録と、人々の記憶が戻る。打ち切りも取り消し（一晩の期限はここで役目を終える）。
     > ネクマックス「よかった。……でも、町を安全に戻す方法は、まだ分からない」
  4. 年月で風化した台座の文様は戻らない（黒い輪が食べたものではないから）。ソピア「昔の人が刻んだ形を、知りたい」。ソピアが碑文から時期を絞る：「水の祭りの夜」。プロジェクトがソピアの研究から作った「生きていた頃の遺跡」の IDO 記録に、背中の鉱石が応えて、扉になる。
  5. **クメール王朝の時代**：大水と「朝を食べる夜」が来る夕方。台座の守り手の娘チャンダは、取り残された人を「夜を越えるための家」へ運ぶのに必死。ネクマックスは手伝う：舟を岸へ引く・橋を支えて大勢を渡す（14章の一人を抱える救助と変える）。市場や高床の家は、水路の向こうの暮らしの景色として見せる。
  6. 夜が来る前に、チャンダが台座で村を閉じる。静かな夜。閉じた空の向こうを、黒い輪が通り過ぎていく（2086年と同じ生き物）。
  7. **夜明け（章の頂点）**：チャンダが東の門から外を見て、黒い輪が去り、水が引いたのを確かめる。台座の仕掛けをネクマックスが支え、**チャンダの合図で手を離す**。村がひらき、人々が東へ向かって言う。「アルン・スオスダイ（おはよう）」。人々が実際に外へ歩き出す。操作が戻り、ネクマックスはその人たちと少し歩ける。
     > チャンダ（外を見て）「水も引いた。……もう大丈夫。離して」
     文様が光り、ネクマックスの背中の鉱石が、同じ光を覚える。
  8. 2028年へ戻り、ソピアと二人で文様を復元する。台座の下の部屋（昔の人が石を掘った古い鉱山の坑道の奥）が開き、光る石が一つだけ見つかる（新仕様 §8「カンボジアの架空の鉱山で発見」に合わせる）。**発見を記録するのはソピア**。ネクマックスの背中の鉱石が、もう一つの石と同じ音で鳴る（この一つきりの石が、のちに初号機に組み込まれる。量産型に無い理由）。
     > ソピア「人を守って、そのあと、また外へ送り出せるように」
     > 社長「うん。そのために、みんなで調べよう」
  9. ダラは、祖母の歌や遊び場に人へ伝えたい歴史があったと知り、自分の言葉で遺跡を案内する。
- **帰還（ソラ その三）**：ネクマックスが持ち帰ったのは、手の離し方の感覚と文様の記録。今朝のソラは、メモと持ち帰った物を読んで、それを町で使える形にすると決める。
  > ソラ「この手順なら、町ぜんぶでもできるかもしれない。……ここからは、私の仕事」
- **得るもの**：鉱石に「安全に戻す」感覚が目覚める（**ひらく**。作者の決定「鉱石の真の力を取り戻す」はここ）。ただし、町ほど大きな守りを、狙った瞬間に解くには、2086年のソラの技術が要る（16章）。
- **2028年の研究者が、なぜ後の開発で「閉じる」しか扱えなかったのか**：復元できたのは、遺跡の台座と扉の扱い方。持ち主が自分の中に作った空間を安全に解く制御は、外から教えられず、持ち主の経験と 2086年のソラの技術で初めて完成する。

### 16章 2086年 → 本物の夜「明日へ」
1. **打ち明ける**：ループの事情は 5章でもう話している。最後に打ち明けるのは、**毎朝忘れられる寂しさと、自分も消えるかもしれない怖さ**。
   > ソラ（羅針盤のメモを見ながら）「このメモ、私が書いたんだね。……覚えてなくても、今の私も同じ気持ちだよ」
2. **小さな約束**：作戦の前、ソラ「終わったら、展示の片づけは二人でやろうね」。
3. **作戦（図は三つだけ）**：ソラが口までの道をつなぐ／ネクマックスが口を外す／離れたら守りを解く。量産型ネクマックスたちが、町の人を広場に集める（新仕様 シーン11）。量産型「旧型サン、避難誘導ハ ボクタチガ。……ソッチハ、オ願イシマス」（1章「同期して、最新の部品に替えます？」の回収）。
4. **止まった夜**：壁を越えると、黒い輪の輪郭がはっきりし、クローに手応えが返る（4章「すり抜ける」を体で回収）。外は、黒い輪が町を飲み込む直前のまま止まっている。周りは止まり、黒い輪だけが動いている（最初にこの規則を見せる）。見慣れた祭りの広場の床が無くなり、止まった破片が足場になる（つかめる破片は、ひと目で分かる形と色）。
5. **口を外す**（新仕様 シーン12「核を引き出し、弱点を露出させる。ソラの合図で解除し、決定打を与える」の流れに沿う）：黒い輪が町の壁に食い込んでいる口（最後の錨。新仕様の「核」）へ。腕の切り替えには足を止められる猶予を置く。二本のワイヤーで口を壁から引き出して弱点を見せ、**ソラの合図で手を離し**、はじくで決定打を入れて口を外す。
6. **確かめる**：口と町の間の黒い引きつれが切れる。口が閉じ、町の光がもう吸われていないと分かる。黒い輪は止まった一瞬から解き放たれ、閉じながら遠ざかる。
7. **守りを解く**：ソラが壁の内側から外の安全を確かめて合図し、ネクマックスが守りを解く（15章のチャンダと同じ手順）。止まっていた夜が動き出し、捕まっていた明日が光になって、それぞれの時代へ帰っていく。
8. **初めての明日**：いつもの朝と同じ構図、違う日付。街頭ビジョン「おはようございます。本日2086年10月19日……」。子どもの風船は、今朝は手から離れない（毎朝の始まりの回収）。
   > ソラ「おはよう、ネクマックス」
   > ネクマックス「おはよう、ソラ」
   > ソラ「昨日、片づけは二人でやろうって言ったでしょ。……昨日のこと、覚えてるよ」
   > （二人で展示の道具を持ち上げる）
   > ネクマックス「うん。じゃあ今日は、何を作ろうか」（新仕様 シーン12）
   - 「覚えてるよ」は、この一日を覚えているという意味。全部の周や、5歳の夜の記憶が戻った意味にはしない。
9. **エピローグ**：各時代のその後を短く。ミチと北條の新しい試作、浜の里の水車と長命草の畑、佐伯と最初のチーム、ソピアの発見の記録とダラの案内、2032年に一つきりの石を背中に宿して生まれる初号機。ソラとネクマックスは、展示のリングで昔の大阪を二人で歩く（1章の約束「君にもIDOを体験させてあげる」）。おはるの写しやミチのノートが、記録の中に残っている。夜の祭りで、ソラ「来年も、こうして回ろうね」（2章の「来年もこうして回れるかな」が、問いから約束に変わる）。二人はこの夜の記録を IDO に残す。次の夜に向き合う誰かのために。

## 8. 裏設定（作者向け。画面での説明は必須にしない）

- **黒い輪（オルム）**：時間の外をただよい、明日を楽しみにする人が集まった夜に降りてきて、まだ決まっていない明日を食べる生き物。悪意は無い。遠い昔、クメール王朝の時代の水の祭りの夜にも降りてきた。そのときの人々は、石で村を**夜が来る前に**閉じ、夜が過ぎるのを待ち、外の安全を確かめてから手を離して村を戻した（15章で見る）。
- **2086年**：黒い輪が町を飲み込もうとした瞬間に（空が割れてから少しあと。2章で鉱石がまぶしく光る瞬間）、ネクマックスの背中の鉱石が**とっさに**町を閉じた。食いついた口が壁に挟まり、黒い輪は町から離れられなくなった。壁の外の夜は、その一瞬のまま止まっている。食べられない黒い輪は、壁を作った者が生まれるまでの過去へ回り込み、その時代に食い込んだ（錨）。ネクマックスが同じ朝へ戻るたび、残っている錨の食い込みは深くなる。
- **決着**：新仕様 シーン12 の「核を引き出し、弱点を露出させ、ソラの合図で解除し、決定打を与える」に沿う。核＝壁に食い込んだ口（最後の錨）。決定打は、口を壁から外す一撃。最後の錨を外すと、黒い輪は止まった一瞬から解き放たれて遠ざかる。町の守りはまだ保たれていて、そのあとネクマックスが守りを解く。「二度と世界へ来ない」までは保証しない。この町への食いつきが終わったことが分かればよい。
- **アルン鉱石**：クメール語で夜明け（朝のあいさつ「アルン・スオスダイ」）。クメール王朝の頃、「夜を越えるための家」の台座に置かれていた。夜のあと、台座の下の部屋に封じられた。その部屋は、昔の人が石を掘り出した古い鉱山の坑道の奥にある（新仕様 §8「カンボジアの架空の鉱山」）。2028年に、社長のプロジェクトの調査でソピアが見つける（一つきり）。2032年、初号機の背中に（新仕様 §8）。初号機だけが持ち主になれる（新仕様 §8.1）。
- **ひらく（真の力）**：自分の石で閉じたものを、安全に終わらせること。異次元拠点の出入りや帰り道は、以前から自動で働いている。15章で覚えるのは、その「終わらせ方」の制御。
- **IDO**：記録を見る仕組みで、時空を越える力は無い（新仕様 §2-4）。背中の鉱石が記録に応えると扉になる。ふつうの人には仮想の記録、ネクマックスには本物の時代への扉。古い港の体験は**本物の時空移動ではなく、展示の復元体験**。
- **羅針盤のメモが次の周に残る理由**：ネクマックスが持ち歩き、鉱石の保存場所に入れているから（9章で一度見せる）。ただし、過去から消えていく名前（13章）は、持ち歩いても欠けていく。

| 目的が変わるときは一言でつなぐ（§4） | 目的のすり替わりが「お使い」に見えるのを防ぐ |

| 台座の二択をやめる | 正解を選ぶまで進めない二択は、決断ではなく確認問題になる |
| 15章の期限は錨を外すまで | 忘却が止まれば打ち切りの理由も消える。そこからは「戻し方を知りたい」で進む |
| 発見の主役はソピア | 十年調べた研究者が、最後に石を他人に渡すだけにならないように |
| 「ひらく」は「自分の作った空間を安全に終わらせる」に絞る | 能力を広げすぎると「食べられた明日は作り直せない」という危機が弱まる |

### 11.2 作者に確認したいこと（Claude と Codex が深めた形）

物語の意味が変わる選択だけを残した。どれも「おすすめ」を選べば、このまま書き進められる。

**Q1. 2068年にネクマックスが救った子を、ソラにするか**
- 背景：新仕様 §8 は「2068年、救助中に石が暴走して 1723年へ」とだけあり、救った相手は決まっていない。
- 案A **二人の関係を深める**：2068年にネクマックスが 5歳のソラを救い、2071年に 8歳のソラがネクマックスを見つけた。互いに救い合っていたことになる。
  - 決めておくこと：5歳のソラは家族と駅にいて事故に遭い、避難の途中ではぐれた。暗くて、互いの顔も名前も分からなかった。だから 8歳の出会い（「それが、きみの名前？」）は、ソラが自分から手を差し出した出来事のまま。
  - 明かし方：11章でソラが手を三回握って「いち、に、さん」と数える。14章の救助で女の子が同じ間と仕草を見せる。説明はせず、プレイヤーが気づく。
  - 負担：偶然の再会が一つ増える。
- 案B **誰にでも差し出す救いを描く**：知らない子を救った過去にする。14章は「とっさに誰かを守る心は、昔からあった」という、まっすぐな感動になる。11章の癖の仕込みは要らない。
- おすすめ：A（Claude・Codex とも）。同じ土地の二人の関係が深まり、偶然は受け入れられる範囲。ただし B でも 14章の感動は十分に作れる。

**Q2. 最後に黒い輪をどうするか**
- 案A **町から退ける**：町への食いつきを外し、遠ざかるのを見届ける。負担：いつかまた来る可能性は残る。
- 案B **消して終わらせる**：二度と来ない安心がある。負担：悪意の無い生き物を消すことになるので、それでも消すしかない理由を物語の中で描く必要がある。
- おすすめ：A（Claude・Codex とも）。明日を食べる生き物を「明日へ送り出す」終わり方が、物語の主題と合う。

**Q3. 決戦で見せたい二人の気持ち**
- 案A **離れて、役割を託す（信頼）**：ソラは壁の内側で道をつなぎ、外の安全を確かめて合図する。ネクマックスは外で戦い、ソラの合図で手を離す。新しい設定は要らない。
- 案B **隣で、危険を分かち合う（熱さ）**：ソラも壁の外へ出て並んで挑む。止まった夜でソラが動ける理由（石の守りの中にいる、など）を足す必要がある。
- おすすめ：A（Claude・Codex とも）。11章の合図と 15章のチャンダの手順を、そのまま最後に回収できる。

**Q4. 佐伯ミチと佐伯玲奈の関係**
- 背景：10章（実装済み）に、同じ名字と、ノートの青いロボットの伏線がある。
- 案A **祖母と孫**：13章「祖母のノートの図で、機械を作る面白さを覚えた」。
- 案B **血縁ではない**：ミチのノートが、別の人の仕事を通じて玲奈に届いた。選ぶなら、血縁でないことに物語上の意味（家族を越えて仕事が届く、など）を持たせる必要がある。
- おすすめ：A（Claude・Codex とも）。同じ名字とノートまで張った伏線を、素直に回収できる。

**Q5. 15章に、社長とネクマックスの二人だけの会話を入れるか**
- 背景：作者の決定は「カンボジアでマツイ社長と再び会って、鉱石の真の力を取り戻す」。社長の役割は「人をつなぐ人」（ソピアを共同研究に招く）にした。発見と記録はソピア。
- 入れる：夜明け前に二人で話す。社長「君みたいなロボットを作るなら、人と一緒に明日を作れるロボットにしたいな」。
- 入れない：社長は再会（「……2年ぶりやな。いや、君にとってはどのくらいぶりや？」）と共同研究の約束だけ。
- おすすめ：入れない（Claude・Codex とも）。13章の「人と一緒に働くロボットにしたい」と重なる。15章は人物も時代も多く、ソピアとチャンダを前に出したい。

**Q6. 古い港（古代）の IDO 体験を、本筋の手がかりにするか**
- 背景：作者「古代はテンポを変えるのにいい。ものによっては採用」。本物の時空移動ではなく、旧駅の展示の復元体験（2〜3分）にすることは合意済み。
- 案A **本筋の手がかり（全員が通る）**：昔の港の体験から、地下の通路の入口が分かる形にする。ただし「昔の石の位置」から「後の時代の通路の入口」を決めるには目印がもう一つ要り、短い息抜きに説明が増える。
- 案B **帰り道の任意体験**：11章の最深部から戻る途中、駅の広場の「舟をつなぐ石」の前で、ソラ「ここ、昔は港だったんだって。……少し歩いてみる？」。綱を合図で離す体験はそのまま。
- おすすめ：B（Claude・Codex とも。§11.4）。v3 は B で書いている。

**Q7. 13章に、75歳のミチを出すか**（Q4 が A のとき）
- 背景：10章（実装済み）でミチ「ねえ、また会える？」ネクマックス「たぶん……ずっと先で」。1970年に 19歳のミチは、2026年に 75歳。
- 出す：発表会の客席にいて、実演のあとに「……ずっと先で、ほんまに会えたなあ」。10章の約束が、本人の口で果たされる。佐伯の「祖母、言ってました」は、ミチ本人が隣にいる場面になる。
- 出さない：佐伯の話（祖母から聞いた青いロボット）だけで回収する。13章の人物が増えない。
- おすすめ：出す（Claude の提案。6 回目の点検で、10章の約束が回収されていないのに気づいて足した）。

### 11.3 このまま進める作業（止めたいときだけ一言ください）
- 「時のかけら」を「時のしずく」に改名し、見た目を丸い光のしずくにそろえる（「欠け」と聞き分けるため）。
- 仕様書 v2.3 の回想の台詞（「昨日のことが分からなくても、今日はここにいるよ」）を、ゲームの台詞「昨日のこと、思い出せなくても大丈夫。今日から、いっしょに思い出をつくろう！」に合わせる。
- 10章の台詞と目的表示に残る「糸」「結び目」「全部吸われた」を、v3 の言葉に合わせる。
- 次に作るのは **11章＋最小の異次元拠点**。同時に、二本のワイヤーと抱える操作を試作する（§7.4）。

### 11.4 Claude と Codex で意見が分かれ、決着した点
- **Q6（古い港を必須にするか）**：Claude は「舟をつなぐ石の展示位置から、保守通路の入口の向きが分かる」で必須にできると考えた。Codex は「石が掘り出された位置が分かっても、後の時代の通路の入口がどちら側かは決まらない。展示場所が発掘場所だという保証も無い」と反対した。Claude もこの指摘が正しいと判断し、任意（B）にした。
- **Q5（社長との二人の会話）**：Claude は短く入れる案だったが、Codex の「13章の構想と重なり、15章が混む」という指摘を受けて、入れない案に変えた。

### 12.4 確かめて、問題なしとしたもの
- ソラ「君の鉱石の光、前より少し弱い」（10章の帰還）：15年見てきた普段の光と比べている。前の周を覚えているわけではない。
- 年齢と年：ソラは 2068年に 5歳 → 2071年に 8歳 → 2086年に 23歳。2071年から 15年（オープニングの独白）。1723年は 1726年の三年前（源兵衛）。ミチは 1970年に 19歳 → 2026年に 75歳。社長は 2026年 → 2028年で「2年ぶり」。
- 2026年の社長は、6章ですでに「人と一緒に働くロボット、ネクマックス」の絵と名前を持っている。13章はそれが消えかける話なので、矛盾しない。
- 古い金具（源兵衛）と、佐伯の固定具は別の物として扱う。
