## 0. v3 の方針

作者の指摘：
- 理屈っぽいけど、内容が理解しにくい。「なぜ？」が抽象的。
- 各時代が有機的につながるように。時代を増やしすぎず、同じ時代の別のフィールドを。古代はテンポを変えるのにいい（ものによっては採用）。
- **共感と感動を生むストーリーに。伏線は上手に回収する**。
- **行動の必然性と、目的が明確であること**。行き当たりばったりのお使いにせず、ストーリーを進めながらやることが明確になっていく。

Claude と Codex で決めたこと（理由は §11.1）：
1. 画面で使う言葉は「黒い環・欠け・錨・守りの壁」の 4 つだけ。説明は三文にして、明かす時期を章ごとに分ける。
2. 各章を「誰の、何を助ける話か」の一文にする。その人が目の前の仕事をやり遂げるのを手伝った結果、ネクマックスの明日も守られる。
3. **守ったことを失敗として裁かない**。成長は「守ること」に「安全に戻すこと」を足すこと。
4. 決着は「黒い環の口を外す → もう吸われていないと確かめる → 守りを解く → 朝」。朝は勝利の結果。
5. **ソラは忘れる。それでも、前の自分が残した仕事を受け取り、今の自分の判断でネクマックスを支える**。中盤で三度、ソラ自身の判断で状況が変わる場面を置く（11章で冒険を進める・12章の帰還でおはるの書き足しに気づく・15章の帰還で最後の作戦を引き受ける）。最後の「昨日のこと、覚えてるよ」は、遊んだ時間への返事になる。
6. 12章 → 13章は順番を固定し、異変を段階的に強くする（刻印 → 右腕 → 名前 → 胸の石）。
7. 台座の二択はやめる。発見の主役はソピア。

## 1. 物語の芯（共感と感動の柱）

> ソラ（8歳）「昨日のこと、思い出せなくても大丈夫。今日から、いっしょに思い出をつくろう！」

- 二人はこの言葉から 15年、思い出を作ってきた（導入編の独白「ソラとつくった思い出なら、15年ぶんある」）。
- 祭りの夜から、同じ一日がくり返す。**ソラは毎朝、前の日を忘れる。覚えているのはネクマックスだけ**。いっしょに作ったはずの思い出が、ネクマックスの中にしか残らない。プレイヤーが最初に共感する寂しさ。
- それでもソラは、羅針盤に自分の字でメモを残す。「ネクマックスを信じて」。そして次の朝のソラは、覚えていないのに、そのメモと前の自分の調べた物を受け取って、**今の自分の判断で**続きを始める。**忘れても続く信頼**が、二人の関係の芯。
- 物語の終わりは、「止まってしまった思い出の続きを、また作れる」朝。ソラが取り戻すのは、全部の周の記憶ではなく、**直前の一日をいっしょに覚えている、ふつうの暮らし**。覚えていない冒険は、残されたメモを二人で読めばいい。

もう一本の柱：**仲間と小さな仕掛けを動かしてきた経験を、自分が町を守り続けている大きな力にも使えるようになる**。7章の水門（源兵衛とおはる）、10章の塔（ミチ）で「支えて、合図で離す」は成立している。15章でその意味が「守りを、安全に終える」へ広がり、16章で最後の合図をソラに委ねる。

## 2. プレイヤーに伝える説明（三文）と、明かす時期

1. 空の黒い環は、**明日を食べる生き物**。祭りの夜、明日を楽しみにする人が集まったナンバタウンへ来た。
2. ネクマックスが知らないうちに町を守っていた（同じ一日のくり返し）ので、黒い環は今度は、**ネクマックスが生まれるまでの過去に食いついた**。
3. **ネクマックスが生まれるきっかけが消えたら、町を守るネクマックスもいなくなる**。だから、過去の人たちを助けに行く。

| 時期 | プレイヤーに分かること |
|---|---|
| 1〜8章 | 黒い環が明日を食べる。同じ一日がくり返す。昔の黒い環を弱めると、未来の環も少し弱まる |
| 9章 | 過去の異変が、自分の体に出ている（固定具の刻印が薄れる） |
| 10章 | 過去の人を助けると、自分の体が戻る |
| 11章 | 町を囲む壁が、自分の胸の石とつながっている（誰が作ったかは、まだ） |
| 14章 | 壁と巻き戻しを動かしていたのは、自分のとっさの反応。同じ朝へ戻るたび、過去の食い込みが深くなる |
| 15章 | 閉じたあと、安全に戻す方法がある |
| 16章 | 口を外して、守りを解いて、明日へ |

画面では、明日が食べられる様子をはっきり見せる：開場予定の看板、来年の約束の貼り紙、未来の街の展示が、黒い環へ吸い込まれていく。**明日を楽しみにした人に落ち度がある描き方はしない**。

## 3. 画面で使う言葉

| 言葉 | 意味（画面で分かる形） |
|---|---|
| 黒い環 | 空に浮かぶ、明日を食べる生き物。名前「オルム」は 14章まで誰も口にしない |
| 欠け | 黒い環に明日を食べられかけて、黒く動き出した物（敵）。倒すと、捕まっていたものが光になって元の持ち主へ戻る |
| 錨 | 黒い環が、その時代に食い込んでいる場所 |
| 守りの壁 | 祭りの町を囲む、白くかすんだ壁（4章で外へ出られなかった壁） |

- 収集物「時のかけら」（1970年に実装済み）は「欠け」と紛らわしいので、**「時のしずく」に改名**し、見た目も丸い光のしずくにそろえる。
- 欠けを倒して戻るのは「食べ尽くされた時間」ではなく「**奪われかけて、捕まっていたもの**」。最終戦で戻る明日も同じ。

## 4. 目的の階段：ストーリーを進めるほど、やることがはっきりする

各章は「いま何のために、何をするか」が一つに決まっている。章の終わりに分かったことが、次の章の目的を生む。目的が途中で変わるときは、**必ず一言で理由をつなぐ**（下の「つなぎの一言」）。

| 章 | 大きな目的 | いまの目的 | つなぎの一言・章の終わりに分かること |
|---|---|---|---|
| 1〜5 | ソラと祭りの夜を越えたい | 夜を止める方法を試す | 背中の石は量産型に無い → 石の正体を知りたい |
| 6〜8 | 石の正体を知りたい・帰りたい | 2026年・1726年で人を助ける | 昔の黒い環を弱めると、未来の環も弱まる |
| 9 | 夜を止めたい | 刻印が薄れる理由を確かめる | 過去の異変が、自分の体に出ている → 原因の時代へ |
| 10 | 自分の体を戻したい | ミチを助けて錨を外す | 過去の人を助けると体が戻る。でも夜の環は消えない |
| 11 | 夜を止めたい | **地下の避難路から、町のみんなを外へ逃がせるか確かめる**。ソラ「前の私のメモに、地上のゲートからは出られなかったって。でも地下の避難路は、まだ調べてない」 | 「下からも出られない。でも、壁は君の石に反応した。次は、この反応を調べよう」（調査はメモに残る。右腕の異変が来ても、放り出した目的にしない） |
| 12 | 体を戻したい | 源兵衛に腕の歯止めのことを聞く。着いてすぐ「お前の腕と、あの水車……同じところが止まっとる。水車を頼む」 → **村へ水を通す** | 自分の腕の仕組みは、源兵衛とおはるの工夫から来ている。ソラが絵図の書き足しに気づく |
| 13 | **ソラに名前を呼んでほしい** | 佐伯の実演を成功させる。佐伯「この実演がなくなったら、ロボットを作る仕事そのものが始まらないんです」 | 自分は、たくさんの人の仕事が重なって生まれた。ほどいた三つの錨が、すべて同じ夜を指す |
| 14 | 夜に何が起きているか知りたい | 胸の石の記録を見る → 「この夜と、同じ反応が前にもある。2068年……地下駅で、何を守ったんだろう」 → 記憶の部屋 | **自分が町を守っていた。守ったことは間違いではない。でも、戻し方を知らない** → 目的が一つにまとまる：守りを安全に解く方法を見つけ、黒い環の口を外して、ソラと明日へ行く |
| 15 | 守りを安全に解く方法を知りたい | ソピアを助け、石が見つかる場所を守る → 錨を外したあとに「町を安全に戻す方法は、まだ分からない」 → 昔へ | 閉じたあと、外の安全を確かめて、合図で手を離せば戻せる。ソラ「ここからは、私の仕事」 |
| 16 | ソラと明日へ行く | 口を外し、守りを解く | 初めての明日 |

「どこへ行くか」は、毎回**体の異変**と**羅針盤の針**の二つで決まる（羅針盤は、ネクマックスにつながる記録のうち、黒い環に噛まれて震えているものを指す）。行き先の時代では、**助ける相手と、その人がやり遂げたい仕事**が一つだけある。遊びの障害は、その仕事の邪魔として出てくる（部品を集めて回る形は 10章だけ）。

## 5. 章ごと（9〜16章）

### 9章 2086年「刻印が消える朝」（一部実装済み）
- **一文**：ソラが、忘れても続けられる調べ方（羅針盤とメモ）を作る話。
- **きっかけ**：朝の整備で、ソラが右腕の固定具を見る。「この刻印、『佐伯』……薄くなってる？」。ネクマックスだけが、朝ごとに薄くなっているのを知っている。
- **流れ**：ソラが源兵衛の絵図と固定具から羅針盤を作る → 針が 1970年の記録に振れる（行き先の根拠）→ ソラがメモを書く。ネクマックス「羅針盤は、ぼくが持っておく。ぼくが持ってる物は、朝に戻っても消えないんだ。源兵衛さんの金具みたいに」（メモが次の周に残る理由。実装済み）。
- 会場の屋台に「長命草だんご――一株で一日長生き」の看板（12章の伏線）。
- **分かること**：過去の異変が、自分の体に出ている。

### 10章 1970年 万博（実装済み）
- **一文**：ミチが、忘れられた先輩の仕事を完成させる話。
- 戻ると刻印が戻る。ソラは羅針盤に残った前の一覧と比べて、消えていた展示が戻ったと気づき、ミチのノートの持ち主が「佐伯」だと知る（実装済み。確かめるのは 13章）。
- 1970年で錨を外した直後の「鉱石が軽くなった」（実装済み）は、錨の負担が軽くなった感覚。帰ってからの「光が少し弱い」は、巻き戻しの消耗。二つは別のこととして扱う。
- **分かること**：過去の人を助けると、自分の体が戻る。ただし夜の環は少し小さくなっただけ。

### 11章 2086年 地下の旧駅「下からの道」
- **一文**：ソラと二人で、町のみんなを逃がせる道を探す話（ソラと一緒に歩ける、唯一の冒険）。
- **きっかけ**：夜の環は消えない。ソラ（メモを読んで）「前の私が書いてる。『地上のゲートからは出られなかった』。……でも地下の避難路は、まだ調べてない。外へ通じれば、町のみんなを逃がせるかもしれない。私、あの駅は知ってるの」（4章の出来事を、ソラは覚えていない。メモで受け取る）。
- **ソラが冒険を進める**：通路の判断、古い装置の操作、安全の確認はソラの担当。ネクマックスが渡る前に、ソラが離れた場所から安全を確かめて合図する（16章の連携の準備）。
- **流れ**：
  1. 白い壁：触ると、胸の石と同じ響きがする。
  2. 閉鎖された地下街：シャッターの重りをクローで引いて通路を開く。広い踊り場で一度だけ欠けと戦う。
  3. 水没したホーム：天井の配管へ飛びつき、振り子で向こう岸へ。途中に、足をつけられる広い場所を置く。
  4. 古い港の IDO 体験（§11.2 Q6 で作者に確認中）：旧駅の保守通路は、昔の堤の上に造られている。施設の図に「旧堤」とあるが、入口は水の下で見えない。旧駅の広場に、工事のとき掘り出された**舟をつなぐ大きな石**が展示されていて、そこに「なんばの昔」の IDO 記録がある。記録の中の古い港（難波津）を 2〜3分歩き、その石に結んだ綱を、港の娘の合図で離す。石が堤の上のどこにあったかが分かり、現在の展示の石の位置から、保守通路の入口の向きが分かる。
  5. 回収施設の跡：ソラ「ここでね、君を見つけたの。8歳のとき」。段差でソラが先に降りて、手を差し出す。「ここ、あのときも降りにくかったんだ」。ネクマックスは覚えている。プレイヤーがその手を取って進む（ソラ自身の思い出なので、ソラも覚えている）。
  6. 最深部：出口は無い。壁は町の下までぐるりと閉じていた。壁の根元が、ネクマックスの胸の光と同じ脈で光る。
     > ソラ「下からも出られない。でも、壁は君の石に反応した。……次は、この反応を調べよう」
- 胸の石が強く光り、**異次元拠点**（ネクマックスの中にある小さな整備室）が開く。装備の付け替えができるようになる。
- 整備室で、源兵衛の古い金具を胸に近づけると、一瞬だけ知らない地下の映像と音が戻る（14章の記憶の部屋への導線）。保全記録の中に、今のものとよく似た「2068年」の記録が見つかるが、中身はまだ読めない。
- （§11.2 Q1 で作者が A を選んだ場合）ソラが怖い場所を歩くときの小さな癖を一つ置く：「こわいときはね、数をかぞえるの。いち、に、さん」。
- **分かること**：壁と自分がつながっている事実（誰が作ったかは 14章）。プレイヤーが「ネクマックスが作った？」と推測するのはよい。
- **戦闘とテンポ**：戦闘は少なく、静かな探索。古い港で一度明るくなる。ボスは置かず、壁と胸が同じ光で応える発見を頂点にする。

### 12章 1726年 浜の里「長命草と水車」
- **一文**：おはるが、倒れたおじいちゃん（師匠）に代わって村へ水を通す話。
- 人物：おはるは源兵衛の孫で弟子（導入編の「おじいちゃん」を維持）。浜の里は、源兵衛の娘でおはるの母・**おせい**（村の薬師）が暮らす村。おはるは、からくりを学ぶために母の反対を押し切って、町のおじいちゃんのところへ出てきた。
- **きっかけ**：右腕で**仕掛けを長く支える（保持する）**ことができなくなる（撃つ・引く・飛びつく・振り子はできる）。整備室でソラが調べても分からない。羅針盤が 1726年に振れる。目的：**金具を知っている唯一の人、源兵衛に聞きに行く**。
- **流れ**：
  1. 仕掛け横丁の工房は空。おはるの置き手紙「おじいちゃん、浜の里で倒れた。うちの村へ来て」。
  2. 横丁の舟着き場から、舟で川を下る（7章で直した水門のそばを通る）。橋桁に引っかかった流木をクローで引く・乗り込んできた欠けを倒す・岸へ飛び移る、の短い場面。
  3. 浜の里：長命草の畑が黒く枯れ、作りかけの水車は止まり、村の人は水車のことを忘れはじめている（錨）。源兵衛は水車を守ろうとして欠けにやられ、熱で寝込んでいるが、一言話せる。
     > 源兵衛「お前の腕と、あの水車……同じところが止まっとる。わしの熱を下げても、それは直らん。……水車を頼む」
     → ここで二つの仕事が見える：源兵衛の熱を下げる（長命草）、水車を動かす（自分の腕と同じ錨）。
  4. おせい「長命草を煎じたら熱は下がる。けど畑のは全部枯れた。残ってるのは、崖の途中の棚だけや」。歩いては降りられない棚。
  5. **はばたき**：源兵衛の図面の箱に「凧の羽」の図。おはるが初めて自分で組み、ネクマックスの左腕に付ける。低い段差で試してから、水車の作業やぐら（クローと足場で登れる）から崖の棚へ滑空する。
  6. **村を一周する道**：作業やぐら → 薬草の棚 → 浜（網や舟の形の欠け）→ 用水沿い → 家と水車。同じ道を戻らない。
  7. 長命草で源兵衛の熱は下がるが、まだ動けない。源兵衛「長命草はな、一日ぶんの明日をくれる草や。……水車は、おはる、お前がやれ」。おせい「お父ちゃんは昔から、人の言うこと聞かへん」。
  8. 水車に絡んだ重い欠けを、はじくとクローで除く（独立したボスではなく、水車を動かす一続きの場面）。
  9. **錨を外す**：ネクマックスは支えられない。おはるが「荷を受け止めてから留め具を外せる仕掛け」を考え、村人と一緒に支える。田植え歌の区切りで、ネクマックスが錨を外す。
  10. 水車が回り、水が畑へ。プレイヤーは水を追って畑までたどる。長命草が青くなり、村が水車を思い出す。おせい「あんたの選んだ道……ええもん作るやないの」。おはるは、自分の仕掛けをおじいちゃんの絵図に書き足す。
- **帰還（ソラ その二）**：右腕が戻る。今朝のソラは何も覚えていないが、羅針盤のメモと、戻ってきた源兵衛の絵図を比べて、気づく。「この書き足し……前の私のメモには無かった。おはるさんの字？ 荷を受け止めてから外す仕掛け……これ、すごいよ」。この発見を 13章へ持っていく。
- **分かること**：自分の腕の仕組みは、源兵衛とおはるの工夫から来ている。

### 13章 2026年 電気街と川沿い「絵が仕事になる日」
- **一文**：佐伯が、社長の構想を実物で支える話。
- **きっかけ**：朝の整備で、ソラがネクマックスの名前を呼ぼうとして、出てこない。「ね……ごめん。君の名前……」。それでもソラは、いつもの手順で腕を点検しはじめる（名前は消えても、関係のすべてが消えたわけではない）。羅針盤のメモの「ネクマックス」の文字も欠けはじめているが、「信じて」の字は残っている（周を越えて持ち歩ける物と、過去から消えていく名前は別、と一度見せる）。羅針盤が 2026年の IDO 発表会の記録に振れる。
- **流れ**：
  1. なんば（6章の場所）に着く。社長のスケッチブックの絵が白くなり、社員はロボットの企画を思い出せない。発表会からロボットの話が外されかけている。社長自身も「なんで僕、ロボットなんか描いてたんやろ」。
  2. 佐伯だけが覚えている。「絵だけじゃ、誰も信じない。動くものを見せたいんです。……この実演がなくなったら、ロボットを作る仕事そのものが始まらない」。
  3. 高架下の作業場所で、ネクマックスが 2086年のソラの気づき（おはるの書き足し）を伝える。佐伯が IDO の記録で源兵衛の絵図を開き、その仕掛けを今の材料で、電磁石の実演機（荷物を受け止めて、そっと離す）にする。同じ仕組みでネクマックスの左腕に**じしゃく**を付ける。
  4. 実演機を発表会場へ運ぶ。電気街の屋根、高架下、川の両岸を横につなぐ道：決まった鉄の看板を引いて道や盾にする・決まった鉄のレールにつかまって滑る。欠けが実演機を狙うので、看板を動かして敵の進路をふさぐ。
  5. 途中で佐伯が話す。「祖母のノートの図で、機械を作る面白さを覚えたんです。祖母、言ってました。万博で、青い小さなロボットに会ったって。……あなたですよね」（10章の回収。刻印が 1970年で戻った理由もここで通る。§11.2 Q4）。
  6. **発表会**：錨は会場の看板の鉄骨。佐伯の実演機が荷物を受け止めて離すのに合わせて、ネクマックスが錨を外す（受付時間は長め）。社長は白くなったスケッチの前で、それでも言う。「この仕組みを、人と一緒に働くロボットにしたい。名前は、ネクマックス」。見ていた人たちが手を挙げ、最初のチームになる。
  7. 社長「次は、カンボジアの子らにも IDO を届けたいんや。遺跡を、その頃の姿で歩けるように」（15章の伏線）。
- **戻るもの**：2086年。ソラ「……ネクマックス」。ネクマックスの返事が、少しだけ遅れる。どれほど怖かったかを知っているのは、ネクマックスだけ。
- **分かること**：自分は、たくさんの人の仕事が重なって生まれた。そして羅針盤の上で、ほどいた三つの錨が、すべて同じ時刻「10月18日、夜」を指している（10章のあとの伏線の回収 → 14章）。

### 14章 2086年「守りの正体」
- **一文**：ネクマックスが、自分が何を守ってきたのかを知る話。
- **きっかけ**：三つの錨が「10月18日、夜」を指す。胸の石の光が、はっきり弱くなっている。目的：**夜に何が起きているのか、胸の石の記録を見る**。
- **流れ（今の記録で証明する）**：
  1. 整備室でソラが、胸の石の保全記録を開く。「保全の発動：10月18日 20時41分」。祭りの夜、空が割れた瞬間の映像と、時刻がぴったり重なる。
  2. 記録には、発動のたびに同じ声が残っている。「もう一度、あの朝に」。1970年で錨がほどけたときに聞こえた声。**自分の声だった**。
  3. 発動の回数と、過去の記録の欠け方が、ぴったり対応している（回数が増えるほど、刻印・絵図・名前の欠けが深い）。**同じ朝へ戻るたび、錨の食い込みが深くなっていた**。
  4. ソラが壁の内と外を図にする。「黒い環の本体は、壁の外。君がクローで触ってたのは、壁に映った姿だったんだ」（4章「すり抜ける」の答え。16章で体で確かめる）。
- **流れ（なぜ閉じたのかを、昔の記憶で理解する）**：
  5. 「この夜と、同じ反応が前にもある。2068年……地下駅で、何を守ったんだろう」。11章で見つけた読めない記録が、源兵衛の古い金具と佐伯の固定具を鍵に、**記憶の部屋**としてひらく。中は 2068年の地下（11章と同じ場所の、18年前。浸水と崩落の救助の夜）。
  6. 前半：**二本のワイヤー**で救助の道を作る。片方で崩れかけた扉を支え、もう片方で自分が渡る（11章で振り子の支点だった配管が、ここでは救助のために使った物だと分かる）。
  7. 後半：取り残された 5歳の女の子を左腕で抱え、右のクローと移動で脱出する。11章では軽く渡れた場所を、重さを感じながら慎重に渡る。女の子が身を縮めたら足を止め、落下物からかばう。抱えている間は戦わない。
  8. （§11.2 Q1 で A のとき）女の子は、怖いときに数をかぞえる。「いち、に、さん」。11章のソラと同じ癖。説明はしない。プレイヤーが気づく。
  9. 天井が落ちる瞬間、胸の石が**とっさに閉じる**。女の子は救助隊の前へ押し出され、ネクマックスだけが 1723年へ落ちる（三年前の源兵衛と出会い、金具を落とす）。戻ったとき機体はぼろぼろで、記憶は胸の奥へ閉じこめられた（新仕様 §8.2）。
- **帰還**：説明より先に、ソラが傷んだ腕に触れる。
  > ソラ「あのときも、手を離さなかったんだね」
  > ソラ「君の力が、みんなを助けてくれたんだよ。……今度は、安全に戻す方法を覚えよう。いっしょに」
- **分かること**：守ったことは、間違いではなかった。2068年も 2086年も、とっさに閉じたからみんなが助かった。ただ、**閉じたあと、安全に戻す方法を知らなかった**。ここで目的が一つにまとまる：**守りを安全に解く方法を見つけ、黒い環の口を外して、ソラと明日へ行く**。
- **二本のワイヤー**：ソラが予備のパーツを整備して、左右に付ける（記憶で使い方を思い出した）。
- **次へ**：胸の石の開発記録「2028年、カンボジアで発見」の行が、一文字ずつ消えはじめる。

### 15章 2028年 カンボジア → クメール王朝の時代 → 2028年「夜明けに手を離す」
- **一文**：ソピアが、祖母から受け取った歴史を残す話。ネクマックスは、守りを安全に終える手の離し方を覚える。
- **きっかけ**：胸の石の「発見」の記録が消えていく。発見が無かったことになれば、ネクマックスの心臓はこの世に無い。ソラが IDO アーカイブで「IDO カンボジア 第1号（登録：マツイ／2028年）」の記録を見つける。開発資料には「閉じる」操作しか残っていないが、「遺跡の台座には、その続きらしい文様があった」と一行だけ書かれている。目的：**石が見つかる場所を守り、閉じたあとの続きを知る**。
- **2028年に起きていること**：社長は 13章で話したとおり、カンボジアの**教育と観光のプロジェクト**を立ち上げた。観光地の遺跡に IDO の石標を置き、子どもたちが自分の国の歴史を歩いて学べるように、旅の人がクメールの都の本当の姿を見られるようにしている。最後の一か所が、考古学者ソピアが祖母の子守歌を手がかりに密林で見つけた遺跡。ここ数日、みんなが遺跡のことを忘れはじめ、明日の朝で調査は打ち切られる。
- **流れ**：
  1. 遺跡の入口、置いたばかりの IDO の石標の前で社長と再会。「……2年ぶりやな。いや、君にとってはどのくらいぶりや？」。ソピアは作業しながら、いつも同じ歌を口ずさんでいる（祖母の子守歌）。
  2. **ソピアを助けて錨を外す**（2028年側の能力の総まとめ：回廊をクローで渡る・崩れた石をはじくで割る・調査用の鉄の足場をじしゃくで引く・崖の水路をはばたきで越える・二本のワイヤーで崩れる梁を支えながら渡る。番人戦は 2028年側に一度だけ）。外す合図は、ソピアがはっきり歌う子守歌「夜が来たら石の家へ、朝が来たら門をひらけ」。
  3. ソピアの十年の調査記録と、人々の記憶が戻る。打ち切りも取り消し（一晩の期限はここで役目を終える）。
     > ネクマックス「よかった。……でも、町を安全に戻す方法は、まだ分からない」
  4. 年月で風化した台座の文様は戻らない（黒い環が食べたものではないから）。ソピア「昔の人が刻んだ形を、知りたい」。ソピアが碑文から時期を絞る：「水の祭りの夜」。プロジェクトがソピアの研究から作った「生きていた頃の遺跡」の IDO 記録に、胸の石が応えて、扉になる。
  5. **クメール王朝の時代**：大水と「朝を食べる夜」が来る夕方。台座の守り手の娘チャンダは、取り残された人を「夜を越えるための家」へ運ぶのに必死。ネクマックスは手伝う：舟を岸へ引く・橋を支えて大勢を渡す（14章の一人を抱える救助と変える）。市場や高床の家は、水路の向こうの暮らしの景色として見せる。
  6. 夜が来る前に、チャンダが台座で村を閉じる。静かな夜。閉じた空の向こうを、黒い環が通り過ぎていく（2086年と同じ生き物）。
  7. **夜明け（章の頂点）**：チャンダが東の門から外を見て、黒い環が去り、水が引いたのを確かめる。台座の仕掛けをネクマックスが支え、**チャンダの合図で手を離す**。村がひらき、人々が東へ向かって言う。「アルン・スオスダイ（おはよう）」。人々が実際に外へ歩き出す。操作が戻り、ネクマックスはその人たちと少し歩ける。
     > チャンダ「閉じたから、みんな朝まで生きられた。外が安全になったら、最後に手を離す。……朝に会うために」
     文様が光り、ネクマックスの胸の石が、同じ光を覚える。
  8. 2028年へ戻り、ソピアと二人で文様を復元する。台座の下の部屋が開き、光る石が一つだけ見つかる。**発見を記録するのはソピア**。ネクマックスの胸の石が、もう一つの石と同じ音で鳴る（この一つきりの石が、のちに初号機に組み込まれる。量産型に無い理由）。
     > ソピア「人を守って、そのあと、また外へ送り出せるように」
     > 社長「うん。そのために、みんなで調べよう」
  9. （§11.2 Q5）夜明け前、社長とネクマックスが二人で話す。社長「君みたいなロボットを作るなら、人と一緒に明日を作れるロボットにしたいな」。
  10. ダラは、祖母の歌や遊び場に人へ伝えたい歴史があったと知り、自分の言葉で遺跡を案内する。
- **帰還（ソラ その三）**：ネクマックスが持ち帰ったのは、手の離し方の感覚と文様の記録。今朝のソラは、メモと持ち帰った物を読んで、それを町で使える形にすると決める。
  > ソラ「この手順なら、町ぜんぶでもできるかもしれない。……ここからは、私の仕事」
- **得るもの**：胸の石に「安全に戻す」感覚が目覚める（**ひらく**。作者の決定「鉱石の真の力を取り戻す」はここ）。ただし、町ほど大きな守りを、狙った瞬間に解くには、2086年のソラの技術が要る（16章）。
- **2028年の研究者が、なぜ後の開発で「閉じる」しか扱えなかったのか**：復元できたのは、遺跡の台座と扉の扱い方。持ち主が自分の中に作った空間を安全に解く制御は、外から教えられず、持ち主の経験と 2086年のソラの技術で初めて完成する。

### 16章 2086年 → 本物の夜「明日へ」
1. **打ち明ける**：ループの事情は 5章でもう話している。最後に打ち明けるのは、**毎朝忘れられる寂しさと、自分も消えるかもしれない怖さ**。
   > ソラ（羅針盤のメモを見ながら）「このメモ、私が書いたんだね。……覚えてなくても、今の私も同じ気持ちだよ」
2. **小さな約束**：作戦の前、ソラ「終わったら、展示の片づけは二人でやろうね」。
3. **作戦（図は三つだけ）**：ソラが口までの道をつなぐ／ネクマックスが口を外す／離れたら守りを解く。量産型ネクマックスたちが、町の人を広場に集める（新仕様 シーン11）。
4. **止まった夜**：壁を越えると、黒い環の輪郭がはっきりし、クローに手応えが返る（4章「すり抜ける」を体で回収）。外は、空が割れた瞬間のまま止まっている。周りは止まり、黒い環だけが動いている（最初にこの規則を見せる）。見慣れた祭りの広場の床が無くなり、止まった破片が足場になる（つかめる破片は、ひと目で分かる形と色）。
5. **口を外す**：黒い環が町の壁に食い込んでいる口（最後の錨）へ。腕の切り替えには足を止められる猶予を置き、最後は二本のワイヤーで口を押さえ、**ソラの合図で手を離す**。
6. **確かめる**：口と町の間の黒い引きつれが切れる。口が閉じ、町の光がもう吸われていないと分かる。黒い環は止まった一瞬から解き放たれ、閉じながら遠ざかる。
7. **守りを解く**：ソラが壁の内側から外の安全を確かめて合図し、ネクマックスが守りを解く（15章のチャンダと同じ手順）。止まっていた夜が動き出し、捕まっていた明日が光になって、それぞれの時代へ帰っていく。
8. **初めての明日**：いつもの朝と同じ構図、違う日付（2086年10月19日）。
   > ソラ「おはよう、ネクマックス。……昨日、片づけは二人でやろうって言ったでしょ」
   > ソラ「昨日のこと、覚えてるよ」
   > ネクマックス「おはよう、ソラ」
   > ソラ「止まってた思い出の続き、また作れるね」
   > ネクマックス「うん。じゃあ今日は、何を作ろうか」（新仕様 シーン12）
9. **エピローグ**：各時代のその後を短く。ミチと北條の新しい試作、浜の里の水車と長命草の畑、佐伯と最初のチーム、ソピアの発見の記録とダラの案内、2032年に一つきりの石を胸に生まれる初号機。ソラとネクマックスは、この夜の記録を IDO に残す。次の夜に向き合う誰かのために。

## 8. 裏設定（作者向け。画面での説明は必須にしない）

- **黒い環（オルム）**：時間の外をただよい、明日を楽しみにする人が集まった夜に降りてきて、まだ決まっていない明日を食べる生き物。悪意は無い。遠い昔、クメール王朝の時代の水の祭りの夜にも降りてきた。そのときの人々は、石で村を**夜が来る前に**閉じ、夜が過ぎるのを待ち、外の安全を確かめてから手を離して村を戻した（15章で見る）。
- **2086年**：黒い環が空を食べはじめた瞬間に、ネクマックスの胸の石が**とっさに**町を閉じた。食いついた口が壁に挟まり、環は町から離れられなくなった。壁の外の夜は、その一瞬のまま止まっている。食べられない環は、壁を作った者が生まれるまでの過去へ回り込み、その時代に食い込んだ（錨）。ネクマックスが同じ朝へ戻るたび、残っている錨の食い込みは深くなる。
- **決着**：最後の錨（壁に食い込んだ口）を外すと、環は止まった一瞬から解き放たれて遠ざかる。町の守りはまだ保たれていて、そのあとネクマックスが守りを解く。「二度と世界へ来ない」までは保証しない。この町への食いつきが終わったことが分かればよい。
- **アルン鉱石**：クメール語で夜明け（朝のあいさつ「アルン・スオスダイ」）。クメール王朝の頃、「夜を越えるための家」の台座に置かれていた。夜のあと、台座の下の部屋に封じられた。2028年に、社長のプロジェクトの調査でソピアが見つける（一つきり）。2032年、初号機の心臓に（新仕様 §8）。初号機だけが持ち主になれる（新仕様 §8.1）。
- **ひらく（真の力）**：自分の石で閉じたものを、安全に終わらせること。異次元拠点の出入りや帰り道は、以前から自動で働いている。15章で覚えるのは、その「終わらせ方」の制御。
- **IDO**：記録を見る仕組みで、時空を越える力は無い（新仕様 §2-4）。胸の石が記録に応えると扉になる。ふつうの人には仮想の記録、ネクマックスには本物の時代への扉。古い港の体験は**本物の時空移動ではなく、展示の復元体験**。
- **羅針盤のメモが次の周に残る理由**：ネクマックスが持ち歩き、胸の石の保存場所に入れているから（9章で一度見せる）。ただし、過去から消えていく名前（13章）は、持ち歩いても欠けていく。

### 11.1 Claude と Codex で決めたこと（理由つき。変えたいときは一言で戻せる）
| 決めたこと | 理由 |

| ソラが前の自分の仕事を受け取り、今の自分の判断で状況を変える場面を三度（11・12・15章） | 最後の「覚えてるよ」を、遊んだ時間への返事にするため。ソラを説明役・待つ人にしない |
| 12章 → 13章の順番を固定 | 異変が「刻印 → 右腕 → 名前 → 胸の石」と段階的に強くなる。名前を忘れられたまま別の章へ行く抵抗をなくす。自由度は再訪で確保 |
| 目的が変わるときは一言でつなぐ（§4） | 目的のすり替わりが「お使い」に見えるのを防ぐ |
| 12章で失うのは「長く支える（保持）」だけ | 飛びつき・振り子まで失うと、登る操作と矛盾する |

| 「ひらく」は「自分の作った空間を安全に終わらせる」に絞る | 能力を広げすぎると「食べられた明日は作り直せない」という危機が弱まる |
| 決着は「口を外す → 吸われていないと確かめる → 守りを解く → 朝」 | 朝を奪う敵に「朝が来たら勝ち」は逆。朝は結果にする |

### 11.2 作者に確認したいこと（Claude と Codex が深めた形）

**Q1. 2068年にネクマックスが救った子を、ソラにするか**
- 背景：新仕様 §8 は「2068年、救助中に石が暴走して 1723年へ」とだけあり、救った相手は決まっていない。
- 案A **二人は、互いを救っていた関係にする**：2068年にネクマックスが 5歳のソラを救い、2071年に 8歳のソラがネクマックスを見つけた。明かし方は、11章でソラの小さな癖（怖いときに数をかぞえる）を置き、14章の救助で女の子が同じ癖を見せる。説明はせず、プレイヤーが気づく。決戦の前に二人の関係に効き、16章の朝がもっと深くなる。弱点は、偶然が重なる印象と、5歳のソラがなぜ地下にいたか（避難中の迷子など）の設定が要ること。
- 案B **知らない子を救った過去にする**：偶然が減る。14章は「とっさに誰かを守る心は、昔からあった」という、まっすぐな感動になる。
- **Claude と Codex のおすすめ：A**（14章で、仕草で気づかせる）。ただし B でも十分に感動を作れる。作者が二人の関係に何を足したいかで選んでほしい。

**Q2. 最後に黒い環をどうするか**
- 案A **町から退ける勝利**：町への食いつきを外し、遠ざかるのを見届ける。悪意の無い生き物と矛盾しない。手応えは「口を外した」瞬間と、そのあとの朝。
- 案B **存在を消して、脅威を終わらせる勝利**：決着がはっきりして、二度と来ない安心がある。
- **おすすめ：A**（Claude・Codex とも）。

**Q3. 決戦で見せたい二人の距離**
- 案A **離れた場所から互いを支える**：ソラは壁の内側で、口までの道をつなぎ、外の安全を確かめて合図する。ネクマックスは外で戦う。11章で積んだ「ソラの合図」と、15章のチャンダの手順の、いちばん大きな回収になる。
- 案B **同じ場所で並んで挑む**：ソラも壁の外へ出る。二人で戦う熱さがある。止まった夜でソラが動ける理由（石の守りの中にいる、など）が要る。
- **おすすめ：A**（Claude・Codex とも）。

**Q4. 佐伯ミチと佐伯玲奈の関係**
- 背景：10章（実装済み）に同じ名字と、ノートの青いロボットの伏線がある。
- 案A **家族の中で受け継がれた仕事**：ミチは玲奈の祖母。13章「祖母のノートの図で、機械を作る面白さを覚えた」。
- 案B **家族を越えて受け継がれた仕事**：名字は同じでも血縁ではなく、ミチのノートが別の人の仕事を通じて玲奈に届いた。
- **おすすめ：A**（実装済みの伏線を素直に生かせる）。

**Q5. 15章で、社長とネクマックスの二人の会話を入れるか**
- 背景：作者の決定は「カンボジアでマツイ社長と再び会って、鉱石の真の力を取り戻す」。役割は「人をつなぐ人」（ソピアを共同研究に招く）で決めた。発見と記録はソピア。
- 入れる場合：夜明け前、社長とネクマックスが二人で話す。社長「君みたいなロボットを作るなら、人と一緒に明日を作れるロボットにしたいな」。社長が、ネクマックスの生き方を言葉にする役が残る（2028年側の会話なので、社長が昔へ同行する設定は要らない）。
- 入れない場合：社長は再会と共同研究の場面だけ。ソピアとチャンダが前に出る。
- **おすすめ：入れる**（短く）。

**Q6. 古い港（古代）の体験を、全員が通る必須にするか、任意にするか**
- 背景：作者「古代はテンポを変えるのにいい。ものによっては採用」。本物の時空移動ではなく、旧駅の展示の復元体験（2〜3分）にすることは合意済み。
- 案A **全員が通る短い必須体験**：旧駅の保守通路は昔の堤の上に造られていて、入口は水の下。駅の広場に展示された「舟をつなぐ石」の記録で古い港を歩き、石が堤のどこにあったかを知ることで、通路の入口の向きが分かる。テンポの変化を全員が味わい、11章の道探しの手がかりにもなる。
- 案B **土地の奥行きを楽しむ任意体験**：11章のあと、帰り道で展示を見られる。探索への集中を切らさない。見ない人もいる。
- **Claude のおすすめは A、Codex は「手がかりの根拠が成立するまでは B 寄り」**（§11.3）。

**Q7. 「時のかけら」を「時のしずく」に改名してよいか**（実装済みの名前と見た目を変える）
- **おすすめ：改名する**。「欠け」と聞き分けられる。

**Q8. 仕様書 v2.3 の回想の台詞（「昨日のことが分からなくても、今日はここにいるよ」）を、ゲームの台詞に合わせて直してよいか**
- **おすすめ：直す**。

**Q9. 次に作るもの**
- **おすすめ：11章＋最小の異次元拠点**（§7.4）。同時に、二本のワイヤーと抱える操作の試作で、いちばん重い技術を早く確かめる。

### 11.3 Claude と Codex で意見が分かれた点
- **Q6（古い港を必須にするか）**：Claude は「舟をつなぐ石」で手がかりの根拠を作れば必須でよいと考える。Codex は前回、「昔の岸の形から未来の通路の位置が分かる根拠が薄い。成立するまで任意に」と指摘した（v3 の「展示の石」の案への Codex の最終意見は、議論の続きで確認する）。
