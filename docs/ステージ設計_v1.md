### 時空裂きのNMクローの「止める」の決まり（ゲームとしての約束）
- 止められるのは「動いている物」だけ（歯車・落ちる石・ふり子・回る鏡・飛んでくる影の弾・敵のふりおろし）。人は止めない。
- 止まるのは 4 秒。止まった物には青い時計の輪が出て、残りの時間が減っていく。
- 一度に止められるのは 1 つ。別の物を止めると、前の物は動き出す。
- 物語の理屈：「裏側には時が流れとらん」（7章 源兵衛）→ 爪の先が物を少し裏側にさしこむと、その物の時間が止まる（10章でソラが言葉にする）。

### 「裂く」の決まり
- 空中の「ゆらぎ」（うすく光る縦のすじ）で J 長押し → 切れ目がひらく（6 秒）。切れ目の向こうに、裏側だけにある物が見える・届く。
- 影（トワのランプからこぼれる影）は、裂く力の爪なら表からでも切れる。黒い手・オルムのすじは、裏側にしかないので「裂く」爪で切る。

## 4. 各ステージの作り（もう少しくわしく）

### 1〜5章　2086 ナンバタウン（くり返しの一日）
- **同じ朝の型**：街頭ビジョン（日付と「◯度目」）→ 風船（毎朝、同じ男の子の風船が同じ電灯に引っかかる）→ ソラの一字一句同じあいさつ。プレイヤーが「同じだ」と気づくための舞台。
  - **毎朝、選ぶ**（前の版と同じ）：風船が引っかかったら「男の子の風船が、電灯に引っかかっている……」→「風船を取ってあげる」／「ソラのところへ行く」（W／S・↑↓ で選んで F、スマホは選択肢をタップ）。
  - 1 度目の朝は「取ってあげる」が先：目標「男の子の風船を取ってあげよう」→ J で引きよせて持つ → 男の子のそばで F（「風船をわたす」）→ お礼。持ったまま J で置くと、風船は電灯へもどる（もう一度取れる）。先にソラのそばへ行ったら、そこでおしまい（風船はだまって返す）。「ソラのところへ行く」なら、お母さん「あとで、係の人に取ってもらおうね」。
  - 2 度目からは、同じ電灯に引っかかる場面を短く見せて（F・タップでとばせる）「（……同じ電灯に、同じ風船）」。選ぶ画面は「ソラのところへ行く」が先（F 1 回で進める）。取ってわたすと、同じお礼。
- **1章のお使い**（いちばん最初の版を v7 にもどした。テンポよく）：
  1. ソラ「『共鳴レンズ』をはめれば…箱の山のいちばん上で、とどかないの」→ レンズを J で取る → ソラのそばで F（「レンズをわたす」）→ わっかの映像が止まる。
  2. ソラ「あとは、北の回廊の中継アンテナ…橋がとちゅうで切れてるんだよね」→ 回廊のふちの金具に J（飛びつく）→ 回廊を北へ → アーチの光る輪に J → WASD でこぐ → Space で飛びうつる（落ちたら、切れた橋の手前へもどす。2 回でヒント）→ アンテナの前で F（つなぐ）。

  3. 会場の大画面に「時代博覧祭、開場！」・紙ふぶき・歓声 → ブースへもどる → ソラ「さすが！ ……最新型じゃなくても、私は、君と作りたいんだ」。

## 6. HUD とシステム
- **光のつぶ**：右上に 7 つの点（石の形のわく）。減る瞬間は点がはじけて消える演出。
- **何度目の 10月18日**：朝の街頭ビジョンと、目標の小さな文字。
- **ボスの体力**：既存のボスゲージ（戦闘システム）を使う。防衛戦は「守る物の体力」。
- **タイマー**：逃げきり（2章）・扉（11・12章）。
- **年代ダイヤル**：ソラのわっかの前で開く画面。左右で年、F で決定。波形 2 本（石と記録）。
- **チェックポイント**：章の頭・ボスの前。ゲームオーバー（体力 0）はボスの前から（光は減らない）。

### 8.4 時空裂きのNMクロー（シェル：`rt.chrono`）
```ts
type ChronoKind = 'freeze' | 'seam' | 'ura'
type ChronoTarget = {
  id: string; kind: ChronoKind; label: string
  point: THREE.Vector3   // 毎フレーム読む（動かしてよい）
  radius: number; enabled: boolean
  seconds?: number       // freeze：止める秒数（既定 4）
  onAct(): void          // 時空裂きのクローで J（freeze：止まる／seam：切れ目がひらく／ura：裂く）
  onThaw?(): void        // freeze：時間が戻った
  onPassThrough?(): void // ura：まだ時空裂きを持っていないときに J（すりぬける）
}
rt.chrono.add(t) / rt.chrono.remove(id) / rt.chrono.unlocked / rt.chrono.frozenId
rt.chrono.slit(pos, { normal?, width?, height?, seconds? })  // 空中の切れ目の見た目
```
- 照準はクローと同じ（`ClawTargetDef` の型 `chrono_freeze` / `chrono_seam` / `chrono_ura`）。`v7_rift_claw` が立つまで freeze・seam は狙えず、ura は狙えて「すりぬける」。
- 右腕の部品は `rift_claw`（つかむ・引く・ぶら下がるもそのまま使える）。
