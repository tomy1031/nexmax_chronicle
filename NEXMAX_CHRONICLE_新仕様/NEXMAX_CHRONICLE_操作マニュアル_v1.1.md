# NEXMAX CHRONICLE ― はじまりの未来 ―

**プレイヤー操作マニュアル／NMClaw仕様 v1.1（2026年10月17日）**  
開発対象：Three.js＋Vite＋TypeScriptによるPCブラウザ版  
開発PC：Apple M1 Mac／メモリ8GB  
**表示する操作説明はキーボードのみ。マウス操作をゲームの必須条件にしない。**  
**設計方針：将来のゲームコントローラー対応を前提とするが、このマニュアルではコントローラーのボタン割り当てを記載しない。**

> この文書はゲームの実装前仕様です。キー配置、射程、移動速度、回復回数などはプレイテストで調整します。旧版v1.0の「両腕に初期装備」「マウスで照準・射出」という設定を廃止します。

## 1. 初期装備：右腕の「つかむNMClaw」ひとつ

ネクマックス本体には左右の腕があり、それぞれに交換式のNMClawパーツを装着できる。**ゲーム開始時は右腕だけに「つかむNMClaw」1個を装備し、左腕は装備なし（通常の手）**。2個の装備枠自体は初めから存在するが、**2個の特殊装備を初期から使用することはできない**。

右腕・左腕への付け替え、および別機能のパーツとの交換は、異次元空間にある装備台（後半は指定の整備地点）で行う。基本の「つかむNMClaw」を初めから捨てさせず、探索に必要な場所では再装備できる。ゲーム進行に必要な装備を失って詰むことはない。

### 1.1 何ができるのか

| 対象 | 行動 | ネクマックスの変化 | 体験 |
|---|---|---|---|
| 軽い可動物（箱、小さな歯車、道具） | ワイヤーを射出してつかむ | **対象物を手元へ引き寄せる** | 手の届かない場所のものを取る |
| 固定された支点（柱、取っ手、屋根の金具） | ワイヤーを射出して接続 | **ネクマックスが支点へ引き寄せられる** | 高所への移動、離れた足場への到達 |
| 頭上の支点 | ワイヤーでぶら下がる | **左右の移動で振り子の勢いをつけ、ジャンプで離脱する** | 谷、路地、ビルの隙間を飛び越える |
| 仕掛けのハンドル／歯車 | つかんで一定位置に保持 | 源兵衛などの仲間が調整できる | 一人では完了できない協力パズル |
| 対応する敵の装備 | つかむ、引く | 盾などが短時間動く | 敵の隙を作る（後半で使用） |

**基本原則：軽いものは「物がこちらへ」、動かないものは「自分が向こうへ」動く。** 仕掛け専用の対象だけは、その場で保持する。プレイヤーが対象の区別を見た目と照準表示から理解できるようにする。

### 1.2 装備の見た目と射出の仕組み

- 「つかむNMClaw」は通常時、右腕に収納された小型の爪とワイヤーの形状。構えると爪の先端が開く。
- ワイヤーは**物体に直接接続する機械式の爪**であり、どんな壁にも張り付く万能な糸ではない。対象として指定された支点や物体にのみ接続できる。
- 初期射程の試作値は**約10m**。連続使用は可能だが、同時につかめる対象は初期では1つのみ。
- 接続に失敗しても短い戻り動作だけで再試行可能。対象のない場所へ射出した場合、体力は減らない。
- 物理挙動をすべてシミュレーションするのではなく、装置・引き寄せは決められた軌道で動かす。振り子移動は限定した支点で、快適さと軽量動作を優先する。

## 2. キーボード操作（マウスは不要）

カメラ操作を方向キーに割り当て、**キーボードだけで移動・照準・ワイヤーアクションを完結**させる。ゲームコントローラー向けの「移動」「視点」「ジャンプ」「Claw発射」「アクション」という独立した操作機能を先に設計し、キーボードへ割り当てる方式にする。

| 操作 | キー | 仕様 |
|---|---|---|
| 前後左右に移動 | **W／A／S／D** | カメラ方向を基準に動く |
| カメラ・照準の方向 | **↑／↓／←／→** | カメラを動かす。Clawを構えたときも使用 |
| ジャンプ／ワイヤー離脱 | **Space** | 地上ではジャンプ。ぶら下がり中は勢いを残して離脱 |
| ダッシュ・回避 | **Shift** | 押している間は高速移動、戦闘中は回避として扱う |
| 話す・調べる・IDOを起動 | **F** | 対象の近くで表示されるアクションを実行 |
| **つかむNMClawを射出／解除** | **J** | 対象につなぐ。接続中にもう一度押すと解除 |
| 基本攻撃 | **K** | 通常攻撃。戦闘の実装後に使用 |
| 対象のロックを切り替える | **R** | 前方に対象が複数ある場合、狙う対象を選ぶ。通常時は自動照準 |
| 左腕の装備を選択 | **Q** | 左腕に装備がない初期状態では選択不可と表示 |
| 右腕の装備を選択 | **E** | 初期装備の「つかむNMClaw」を使用 |
| 異次元空間を開く | **G** | 解放後、安全なチェックポイントでのみ使用 |
| 装備・記録メニュー | **Tab** | 装備台以外では交換できない。所持品の確認は可能 |
| 一時停止・設定 | **Esc** | 中断、操作一覧、キー設定 |

### 2.1 視点と狙い方

- 画面中央に小さな照準を表示する。方向キーでカメラを動かし、狙う対象を中央へ近づける。
- つかめる対象が前方に入ると、照準が自動的に吸い付き、対象の輪郭が表示される。**細かなマウス照準は不要**。
- 複数の対象が近くにある場合だけ、`R`で対象ロックを切り替えられる。未ロックのときは最も見やすい対象を自動選択する。
- `J`を押すと接続し、接続中にもう一度`J`を押すと離す。**ボタンを押しっぱなしにする必要はない**。
- 固定支点からぶら下がったときは、`A`／`D`で振り子の方向を調整し、`Space`で勢いを残して飛び出す。飛び移りに失敗しても近くのチェックポイントに復帰できる。
- 初期から一つのワイヤーで空中移動を楽しめる。ただし**二本のワイヤーで連続的に飛び回る操作**は、左腕の装備追加後に検討する。

### 2.2 特殊な場面での操作

| 状況 | 入力 | 結果 |
|---|---|---|
| 木箱を狙ってJ | J | 木箱がネクマックスの手元へ引き寄せられる |
| 高い金具を狙ってJ | J | ネクマックスが金具の近くまで引き寄せられる |
| 頭上の金具につながる | WASD／Space | 揺れの向きを調整し、Spaceで跳び出す |
| 歯車を支えている | J | 支えている歯車から爪を外す |
| 左腕未装備でQ | Q | 「左腕：装備なし」と表示し、移動操作は妨げない |
| ワイヤー移動中にG | G | 異次元拠点へは移動できないことを表示 |

## 3. 交換式NMClawの成長

| 段階 | 右腕 | 左腕 | 新しくできること |
|---|---|---|---|
| **初期** | **つかむNMClaw** | **装備なし** | 物を引く、支点に移動、限定支点で振り子移動、仕掛けを保持 |
| 江戸時代で源兵衛と協力 | つかむNMClaw | 装備なし | 源兵衛の仕掛けを使った連携。新しいパーツの設計を知る |
| 異次元拠点で装備台が解放 | 好きな腕に付け替え可 | 空き枠を使用可 | 右・左の装着位置を交換できる |
| 追加NMClaw入手後 | 1種類を装着 | 別の1種類を装着 | 左右で異なる機能を使い分ける |
| 中盤以降 | 射程や固定力を強化 | 盾・磁力など別用途のパーツ（候補） | ワイヤー移動と仕掛け操作を組み合わせる |

**装備スロットは左右各1つ。** 初期に2つ装備していなくても、最終的には2種類のNMClawを組み合わせられる。パーツ交換は異次元拠点または指定の整備地点に限る。戦闘中に瞬時に交換することはできない。二つを装備できるようになった後、保持を維持したまま別の腕を使う組み合わせは後続の機能として検証する。

## 4. IDOの操作と時空移動

**2086年**：ソラが発展させたIDOのVR展示を`F`で体験できる。通常は歴史を再現した映像体験であり、誰も本当の過去へは移動しない。ネクマックスが「2026年・自分の始まり」を調べた際だけ、体内の特殊鉱石が反応し、初めて本物の異次元の扉が開く。

**2026年**：マツイ社長が紹介するIDOのQRコードを`F`で調べる。普段は歴史の映像を視聴するだけだが、ネクマックスがからくりの記録を読んだとき、再び鉱石が反応し、偶然1726年へ飛ぶ。

**1726年**：QRコードは存在しない。時空移動後の出発地点と帰還先の情報はネクマックスの内部記録に保存され、安全地点から帰還する。序盤の時空移動は偶然のイベントであり、好きな年代へ何度でも自由に移動できる仕様ではない。

## 5. 異次元空間・回復・制限

| 項目 | 初期仕様案 | 制限の目的 |
|---|---|---|
| 体力 | **5目盛り** | 被弾や落下のリスクを明確にする |
| 回復 | 安全なチェックポイントで**1回の全回復**（初期値） | 無制限の回復を防ぐ |
| 出入り | 解放後、指定の安全地点で`G` | 危険な場所からの無制限の離脱を防ぐ |
| 使用できない状況 | 戦闘中、落下中、ボス戦中、ワイヤー移動中 | 難所を飛ばせないようにする |
| NMClaw装備交換 | 異次元拠点の装備台、特定の整備地点 | 装備選択に意味を持たせる |
| 収納 | 初期8枠（仮） | 素材管理を複雑にしない |
| 体力0 | 最後のチェックポイントへ復帰 | 長時間のやり直しを防ぐ |

体力・回復回数・収納枠は**未確定の調整値**。特殊鉱石による大きな時間巻き戻しは物語イベントであり、通常のゲームオーバー時に祭りの朝へ戻る仕組みとはしない。

## 7. 画面表示・操作ガイド

- **左上**：体力5目盛り、時代と場所、必要に応じて特殊エネルギー。
- **中央**：照準。つかめる対象は形状と色で区別（軽い物／固定支点／協力装置）。対象のない時は邪魔にならない小さな表示。
- **右下**：現在選択中のNMClawと、その腕がつかんでいる対象。初期は右腕のみ使用可。
- **左下**：左腕の装備枠。未装備時は「装備なし」。2個目入手後に機能を表示。
- **画面下**：必要な時だけキー案内（例「J：つかむ」「Space：離脱」）。
- **メニュー**：装備、IDOで見た記録、操作一覧、キー設定、セーブ。

PC版の画面内の説明では**マウスの絵、マウスクリック、ゲームコントローラーのボタン名を表示しない**。将来コントローラーに対応しても、**同じ機能名を別の入力機器へ割り当てる**設計にする。

## 8. Three.jsでの実装上の取り決め

1. **操作入力を描画処理から分離**する。`move`, `look`, `jump`, `dash`, `interact`, `claw_fire`, `claw_release`, `attack`, `select_left`, `select_right`, `open_hub`などのゲーム内操作を定義し、最初はキーボードに対応づける。コントローラー対応時は入力を追加するだけにする。
2. **中央照準＋補助照準**を使う。キーボードの方向キーでカメラを動かせるようにし、ポインターロックとマウス移動を必須にしない。
3. **対象の種類をデータで分類**する。`pull_object`, `pull_player`, `swing_anchor`, `hold_mechanism`。種類で射出後の動作を決める。敵用の対象分類は後から追加する。
4. **ワイヤーの表示は軽量な線・簡易メッシュ**を使う。固定支点での移動は決まった曲線に沿って補間し、振り子挙動は許可した支点だけで軽量に再現する。M1 8GBで多数のワイヤーを同時に物理演算しない。
5. **片腕1パーツ・初期1個**をシステム上の状態として扱う。`left: null`、`right: grapple_claw`。装備解放前に左腕の特殊能力を発動させない。
6. 時代と異次元拠点は別のThree.jsステージとし、不要なジオメトリやテクスチャを解放する。プレイ可能なFPSはM1実機で測定する。

## 9. 操作・仕様の受け入れテスト

- [ ] キーボード操作だけで移動、カメラ、ジャンプ、IDO操作、NMClawの射出・解除が可能。
- [ ] マウスを触らずに、頭上の支点へ照準を向けられる。
- [ ] 開始時は**右腕だけ**に「つかむNMClaw」、左腕は未装備。
- [ ] 初期Clawで軽い物を引き寄せ、固定点へ移動し、許可された支点で振り子移動できる。
- [ ] `J`を一度押すと接続、もう一度押すと解除。長押し不要。
- [ ] `Space`でワイヤーから安全に離脱し、移動の勢いを保てる。
- [ ] `Q`で未装備の左腕を選択しようとしてもエラーや進行不能にならない。
- [ ] 異次元拠点で左右の装着位置を交換できる。新しい装備を入手後は両腕に別のパーツを装着できる。
- [ ] 初期の江戸パズルは、片腕のClawだけで解ける。
- [ ] 戦闘中・空中のワイヤー移動中は異次元拠点を開けない。
- [ ] コントローラー対応時にアクションを再利用できるよう、入力処理とゲーム機能が分離されている。
