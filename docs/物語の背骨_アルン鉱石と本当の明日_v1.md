## 1. 物語の芯：ソラの約束

> ソラ（8歳）「昨日のこと、思い出せなくても大丈夫。今日から、いっしょに思い出をつくろう！」

15年前、記憶をなくしたネクマックスにソラがかけた言葉。ネクマックスはこの言葉を支えに、ソラと「今日」を積み重ねて生きてきた。

ところが祭りの夜、ネクマックスは**ソラを失いたくない**一心で、祭りの一日を泡の中に閉じ込めてしまう。泡の中では同じ一日がくり返され、ソラは毎朝、前の日の思い出をなくす。**いっしょにつくったはずの思い出を覚えているのは、ネクマックスだけ**。ソラを守ろうとした力が、ソラとの約束を壊している。

物語は、ネクマックスがこのことに気づき、「今日を守る」ことから「明日をいっしょに迎える」ことへ、自分で踏み出すまでの話。最後の朝、ソラが「昨日のこと、覚えてるよ」と言うとき、15年前の約束がはじめて本当になる。

## 2. 世界の仕組み（確定版）

### 2.1 アルン鉱石
- **見つかった場所**：カンボジア。アンコールワットから離れた密林の奥にある、地図から消えかけた遺跡（架空。以下「忘れられた遺跡」）の地下。新仕様 §8 の「架空の鉱山」は、この遺跡の地下の坑道とする。
- **見つけた人**：2028年、現地の考古学者ソピアと、日本の開発チーム（マツイ社長が同行）。
- **名前**：遺跡の碑文に刻まれていた呼び名「アルン」。クメール語で**夜明け**。朝のあいさつ「アルン・スオスダイ（おはよう）」のアルン。開発の記録名は ARUN。
- **古代の使い方**：洪水や戦の「夜」が来たとき、人々は村をアルンで包んで**閉じ**、時間の外で夜を越した。夜が明けると、遺跡の「暁の台座」の文様で**ひらき**、村ごと本物の朝へ戻った。忘れられた遺跡は「夜を越えるための家」だった。
- **碑文**：「アルンは夜を閉じる石ではない。朝をひらく石である」
- **二つの働き**
  - **とじる**：時間から切り離した小さな空間（泡）を作り、中の「今」を保存する。新仕様の「時間保全機能」と「異次元空間（整備室・保存空間）」は、どちらもこの働き。
  - **ひらく**：保存した「今」や記録を、**本物の時間の流れのぴったり一点**へつなぐ。泡を本物の朝へ戻す力。これが**真の力**。

### 2.2 オルム（名前は 14章まで誰も口にしない）
- 新仕様のとおり、**これから訪れる時間を喰う、独立した未知の存在**。感情も交渉の意思も見せない。アルンや IDO が生んだものではない。
- 未来は、昔の誰かが自分の「イマ」に向き合って動いた瞬間から伸びてくる。オルムは 2086年の明日を喰うために、その根元（いろんな時代の「明日のはじまり」）に**錨**を下ろしてかじる（中盤案 §1.5）。
- 錨はすべて、**本物の 10月18日の夜にいるオルムの核**から伸びている。

### 2.3 2086年のループの正体：泡の中の博覧会
- 祭りの夜、オルムが空を喰いはじめた瞬間、ソラを守りたい一心でアルンが働き、**ナンバタウンの祭りの会場を泡の中に閉じた**。泡は本物の 2086年10月18日の夜から切り離され、中では保存した朝からの一日がくり返される。
- **ネクマックスだけが覚えている**のは、泡を作っている本人だから（新仕様 §3.3 の「異次元空間に自分の記録が保存される」と同じ）。
- **町の外へ出られない**（4章「ソラと町の外へ」で白くかすんで広場へ戻される）＝泡の壁。
- **毎晩、空が割れる**＝オルムが泡に指をかけ、泡ごと喰おうとしている。泡はそれを押し返して朝へ戻る。
- **クローがすり抜ける**（4章「立ち向かう」）＝泡の中にいるのはオルムの影で、本体は泡の外、本物の夜にいる。
- **代わりに、アルンの力が減っていく**。巻き戻すたびに守れる範囲が小さくなり（新仕様 §3.3）、力が尽きると泡ははじけて、みんなは「喰われたあとの本物の夜」へ落ちる。
- だから**本物の時間軸で、オルムの核と戦わなければならない**。泡の中でいくら戦っても終わらない。

### 2.4 IDO と時空移動（なぜ偶然で、なぜ狙えなかったのか）
- IDO は記録（場所と時刻の写真・映像・立体記録）を見る仕組みで、時空を越える力は無い（新仕様 §2-4）。記録の石標の QR に入っているのが **IDO コード**（場所＋時刻の記録の番地）。
- アルンは記録に反応して、その記録のまわりを**閉じよう**とする。そのとき作った泡が、記録の場所・時刻の本物の時間とたまたま重なると、扉になる。これが偶然の時空移動（2086→2026、2026→1726）。
- とじる働きだけなので**狙いが粗く**、アルンがよく知っている記録（自分の出発地点・自分にゆかりのある記録）にしか開かない。帰りに「出発地点の記録」を頼りにするのもこのため。
- ソラの**羅針盤**は、アルンがどの記録に強く反応するかを針で示す道具。強く反応するのは、オルムの錨がある記録と、アルン自身にゆかりのある記録。

### 2.5 ぴったり一致する IDO コード
本物の襲撃の夜へ行く扉は、**泡が本物の時間から切り離された瞬間（縫い目）**にしか開けない。少しでもずれると、喰われたあとの空っぽの夜か、襲撃の前の昼に出てしまい、泡の中のみんなを本物の時間へ戻せない。コードは 3 つの記録を重ねて組む：

| 記録 | 中身 | どこで手に入るか |
|---|---|---|
| ① 場所 | 祭りの会場まるごとの精密な立体記録 | ソラの IDO 展示（博覧祭のために作った記録。1章から会場にある） |
| ② 時刻 | 錨の糸の向き。錨はすべて核から伸びているので、3 本の糸が交わる点が襲撃の瞬間 | 10章 1970年・12章 1926年・13章 難波津で錨をほどくたびに 1 本ずつ |
| ③ 縫い目 | アルンが泡を作った瞬間の記録 | アルンの中。読めるのは「ひらく」働きだけ（15章のあと） |

ソラが 3 つを重ねてコードを組み、量産型ネクマックスと未来の技術者たちが送信の装置を作り（新仕様 シーン11）、ネクマックスがアルンの「ひらく」で扉にする。

## 3. 真の力「ひらく」と、なぜ得られていなかったのか

### 3.1 真の力とは
**保存した「今」を、本物の時間のぴったり一点へつなぎ直す力**。泡を本物の朝へ戻す、記録を正確な扉にする、オルムの核を「今」の時間へ引き出す（新仕様の最終戦の要件）――どれもこの力でしかできない。

### 3.2 得られていなかった理由は二つ。両方そろって、はじめて目覚める
1. **もの（台座）**：アルンは遺跡の「暁の台座」から掘り出された。台座には**ひらくための文様（古代の人の手順＝いちばん古い IDO コード）**が刻まれていて、石は台座の上でしか、ひらき方を知らない。2028年の発掘では石だけを持ち出したので、開発チームが知ったのは「とじる」（収納・避難・一時的な保全）だけだった。新仕様 §3.3「製作者たちはその力を収納・避難・一時的な保全として研究した」と一致する。
2. **こころ（失いたくない気持ち）**：アルンは持ち主の心に応えて働く。2068年の救助の夜も、2086年の祭りの夜も、ネクマックスを動かしたのは**失いたくない**という気持ちで、アルンはそれに応えて「とじた」。ひらくには、明日がどんな日でも――何かが変わっても、失うかもしれなくても――**いっしょに迎えたい**と自分で選ぶ心が要る。記憶をなくし、ソラと過ごす「今日」だけを頼りに生きてきたネクマックスは、今日を守ることしか知らなかった。

文様は石ではなく**持ち主の心に刻まれる**。だから一度ひらき方を覚えれば、台座を離れても使える。そして、アルンのまわりに予期せぬ学習回路が育った**初号機だけ**が持ち主になれる（新仕様 §8・§8.1。量産型には再現できない）。

### 3.3 どうやって取り戻すか（15章）
- 台座の文様を**ソピアが読み、マツイ社長が「何のための石か」を言葉にする**（知恵）。
- 夜明けの台座の前で、アルンがくり返しの朝を見せる。ネクマックスは**自分で明日を選ぶ**（意志）。
- 夜明けの光が台座に届き、文様がネクマックスの心に刻まれる。アルンの光が青紫から**暁の金**に変わる。

## 6. 15章 2028年 カンボジア「忘れられた遺跡」

### 6.1 どうやって行くのか
14章のあと、ネクマックスは「閉じることしかできない自分」に打ちのめされる。ソラは整備室でアルンの開発記録を探し、こう見つける：
> 特殊鉱石 ARUN：2028年、カンボジア「忘れられた遺跡」の地下で発見。発見時の記録：IDO カンボジア 第1号（登録：マツイ）

羅針盤の針が、これまでにないほど強く振れる。錨ではなく、**アルンのふるさと**の記録。ソラ「君の石が、帰りたがってる」。

### 6.2 舞台
- アンコールワットから離れた密林の奥。崩れた回廊、根に飲まれた塔、水路と貯水池、地下の坑道、東を向いた**暁の聖堂**（夜明けの光がまっすぐ台座に届く）。
- 遠景にアンコールワットの塔の影を見せるだけにし、実在の遺跡の中には入らない（敬意を払い、架空の遺跡で描く）。
- 雨季の終わり。朝霧、虫の声、遠くの僧院の鐘。

### 6.3 人物
- **マツイ社長（2028年）**：2026年にネクマックスと会ってから 2年。ネクマックスの構想を形にする仲間と材料を探していて、IDO の海外協力でカンボジアに来た。
- **ソピア**（30代・現地の考古学者）：祖母の子守歌でしか知られていなかった遺跡を探し当てた人。碑文を読む。
- **ダラ**（村の少年）：遺跡を遊び場にしている。ネクマックスを「森の青いの」と呼ぶ（寄り道の案内役）。

### 6.4 なぜ「忘れられた」のか
遺跡そのものに**オルムの錨**が下りている。ひらく力の生まれた場所は、オルムにとっていちばん邪魔な場所だから。可能性を吸われた遺跡は、村の誰の記憶にも残っていない。覚えているのは、ソピアの祖母の子守歌と、古い調査写真が一枚だけ。

### 6.5 流れ
1. **到着**：密林の中。マツイ社長「……ほんまに来たんか。2年ぶりやな、ネクマックス。いや、君にとってはどのくらいぶりや？」
2. **忘れられた遺跡**：村の人は誰も遺跡を覚えていない。ダラだけが「森に石の家がある」と言う。ソピアの子守歌「夜が来たら石の家へ、朝が来たら門をひらけ」。
3. **碑文**：「アルンは夜を閉じる石ではない。朝をひらく石である」。ネクマックスの胸の石が、地下から響く音と同じ音で鳴る。
4. **遺跡の奥へ**（アクション。これまでの腕パーツを全部使う総まとめ）：回廊をクローで渡る／崩れた石をはじくで割る／錆びた鉄の格子をじしゃくで引く／崖の水路をはばたきで越える／欠け（ナーガの欄干や石像の形）との戦い。
5. **夜の番人**（遺跡の錨の番人）：遺跡を守っていた古い石の守り神が、可能性を吸われて錨に結びつけられたもの。ほどくときの合図は、**ソピアの子守歌**（その時代の人の「イマ」）。
6. **暁の聖堂で夜明けを待つ**：社長と二人きりの夜。
   > マツイ社長「君を作るって決めたとき、ひとつだけ決めてたことがある。人の明日を、人と一緒に作るロボットにしたい。守ってばっかりの機械やなくてな」
   > ネクマックス「ぼくは、ずっと守ってばかりだった。ソラを、今日の中に閉じこめて」
   > マツイ社長「ほな、今から覚えたらええ。……昨日が分からんでも、今日から作れるもんはある」（ソラの言葉と重なる）
7. **台座の試練**：台座に手をかざすと、アルンがくり返しの朝を見せる。安全で、ソラが笑っていて、でも明日が来ない朝。「もう一度、あの朝に」と言っていたのは自分の声だった。
   - 選ぶ：「このまま、今日を守る」／「明日へ行く」。前者を選ぶと、同じ朝がもう一度来るだけ。最後はプレイヤーが自分で「明日へ行く」を選ぶ（何度でも選び直せる）。
   > ネクマックス「明日がどんな日でも、ソラといっしょに迎えたい。……忘れた昨日の代わりに、明日を作りたいんだ」
8. **夜明け**：東の門から光が差し、台座の文様が光る。アルンの光が青紫から暁の金へ。
   > ソピア「アルン・スオスダイ。……『おはよう』って意味よ」
9. **社長の決断**：
   > マツイ社長「この石を、君の心臓にする。閉じこめるためやなくて、朝を迎えるために」
   社長は遺跡の記録を IDO に登録する（→ 2086年のソラが見つけるコード）。
10. **帰還**：ネクマックスは初めて、**ひらく力でぴったりの場所へ**帰る。泡の中、ソラのいる展示の前へ。

### 6.6 遊びで変わること
- **ひらく**：止まった物（泡で閉じた物・時間の止まった扉）を本物の時間へ戻す。たとえば崩れた橋を「崩れる前の今」に戻して渡る、止まった水車を動かす。
- 一度ほどいた錨の時代へ、**ぴったりの場所に**行けるようになる（ファストトラベル。異次元拠点から）。
- 体力の上限：これまで集めた時のかけらを、アルンが「明日の分の力」に変える（中盤案の時のかけらの回収）。

## 7. 16章 最終章：本物の 10月18日の夜へ

1. **打ち明ける**：泡の中の朝。ネクマックスはソラにすべてを話す――会場を泡に閉じたのは自分で、ソラが毎朝忘れるのもそのせいだと。
   > ソラ「……知ってたよ、少しだけ。毎朝、羅針盤に私の字でメモがあるの。『ネクマックスを信じて』って」
   （羅針盤はネクマックスが持ち歩き、異次元空間に入れて守っていたので、メモだけはくり返しを越えて残っていた）
   > ソラ「昨日のこと、私だけ思い出せないのは、ちょっとくやしいな。……明日へ行こう。いっしょに」
2. **コードを組む**：① ソラの展示の会場の記録、② 3 本の錨の糸が交わる襲撃の瞬間、③ アルンの縫い目（ひらく力で読む）。量産型ネクマックスたちが会場の人を広場に集め、1章で直した**中継アンテナ**から送信する。
3. **扉をひらく**：泡の縫い目から、本物の夜へ。泡の中のみんなは泡に残ったまま守られている。ソラは展示のリングから扉を支え、合図を送る役。
4. **本物の夜**：喰われかけた空、輪郭を失った街。錨をほどいた分だけ、オルムは弱っている。つかむ・はじく・じしゃく・はばたき・二本のワイヤーで戦い、**ひらく**で核を「今」の時間へ引き出す（新仕様 シーン12）。最後は**ソラの合図で離す**（1726年の水門、1970年の錨と同じ「ええ時に離す」の、いちばん大きな形）。
5. **決着**：オルムの中に溜まっていた「来なかった明日」たちが光になって、それぞれの時代へ帰っていく（1970年の光と同じ）。
6. **泡をひらく**：アルンのひらく力で、泡の中の祭りの一日を本物の時間へつなぐ。くり返した朝の分の「今日」は消えるが、ネクマックスの中には記録として残る。
7. **初めての明日**：2086年10月19日の朝。
   > ソラ「おはよう、ネクマックス。……昨日のこと、覚えてるよ」
   > ネクマックス「おはよう、ソラ」
   > ソラ「15年前に言ったでしょ。今日から、いっしょに思い出をつくろうって。……今度は、ちゃんと明日まで持っていけるね」
   > ネクマックス「うん。じゃあ今日は、何を作ろうか」（新仕様 シーン12）

## 8. 伏線と回収

| 伏線（出した場所） | 回収 |
|---|---|
| ソラ「今日から、いっしょに思い出をつくろう」（1章 回想） | ソラが毎朝忘れる（3〜5章）→ 最後の朝「昨日のこと、覚えてるよ」（16章） |
| 「この町から出られない」（4章 町の外へ） | 泡の壁（11章） |
| 「クローがすり抜ける」（4章 立ち向かう） | 泡の中のオルムは影。本体は本物の夜（11章・16章） |
| 帰りは「出発地点の記録」頼み（7章） | とじる働きだけでは狙いが粗い（11章・15章） |
| 鉱石が錨をほどくたびに光る・「何かをずっと支えていたみたいに軽くなった」（10章） | 泡を支えていたのはアルン（14章） |
| ソラ「君の鉱石の光、前より少し弱い」（10章のあと） | 巻き戻すたびに力が減る（14章） |
| ささやき「もう一度、あの朝に」（10章 錨がほどけたとき。「どこかで聞いたことがある」） | 自分の声だった（14章・15章 台座） |
| ほどけた糸の端が「どこか遠い夜」を指す（10章）／羅針盤に残った時刻「2086年10月18日、夜。……今日？」（10章のあとのソラ） | 時刻の糸。3 本そろうと襲撃の瞬間（14章）＝本物の夜（16章） |
| ミチ「あなたの石、時間を数えてるみたいに光ってた」（10章） | アルンはくり返しの数だけ朝を保存している（14章） |
| 源兵衛「お前、また来たんか」・古い金具（7章） | 2068年にひらけないまま 1723年へ流された（14章） |
| 佐伯ミチと佐伯玲奈（10章のあと） | 祖母と孫。玲奈が固定具を作り、開発へ（後半） |
| ミライ号「おはようございます」（10章） | アルン・スオスダイ（15章）、最後の「おはよう」（16章） |

「おはよう」はこの物語の合図の言葉。ミライ号のあいさつ、アルン（夜明け）の名前、最後の朝のソラ。どれも「明日が来た」ことを告げる言葉として置く。
